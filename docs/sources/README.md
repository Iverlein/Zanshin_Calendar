# Sources for the open readings

The texts behind the roadmap's T2 and T3 items, one topic per file, with the
Tibetan as printed and its content restated in English (SPEC §8: facts in
our own words). How to read them is in [PLAN.md](PLAN.md), and how several
are read at once, a subagent each, in [PROTOCOL.md](PROTOCOL.md);
what is still to be read, and why, in the work plan of
[ROADMAP.md](../ROADMAP.md) (T2). The layout the pool grows into (a corpus file
per source chapter, claims, question files, passage ids) and the index that
reads it, `tools/sources/kb.py`, are in [STRUCTURE.md](STRUCTURE.md).

## How the files quote

- **The scan wins.** A quotation is read on the page image. Where only the
  OCR was available, the file says so. […] marks a syllable the scan does
  not show clearly; a reading that is a guess says so.
- **The Tibetan is kept**, not only the English: each passage read is
  written out in Tibetan script as the scan shows it, the whole passage
  and not only the line used (PLAN.md, *The knowledge pool*).
- **Tibetan as printed**, spelling and the 1996 editors' bracketed numbers
  included. A normalized spelling is given next to the printed one, never
  instead of it.
- **English in our own words.** The Tibetan works are public domain;
  modern English translations (Henning, Berzin, Gyurme Dorje) are not, so
  their facts may be used but not their wording.
- **Each fact names its edition, page and image number**, so that it can be
  checked without searching.

**SN is a witness, never a source** (the owner, 2026-10-08). It may confirm
a reading of WB or raise a question about one, and a topic file may quote
it for that. Nothing that only SN gives (a reading, a list, a date, a rule
WB does not state) enters the app, its catalog or its `Sources`; the app
cites WB. The same holds for any other Bon text, among them Khyung sprul's
*dpyad gsum dag rtsis*, a reformed calendar arithmetic not used at all
([tibetastromed.md](tibetastromed.md)).
