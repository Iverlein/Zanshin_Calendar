# No Sanskrit original of the Svapnohana is named in the Indian sources read (RD272)

No Sanskrit original of the *Svapnohana* is named in any Indian source RD272 read. The *Śabdakalpadruma*'s article *svapna* (skd:p470-473) never names the work; Negelein's 1912 print (the Introduction's list of his texts a–w, his notes to 1.15–17, p. 32, p. 376) names no *Svapnohana*, *Svapnaparīkṣā* or like title, and the *Svapnādhyāya* texts it does name (a Bṛhaspati's, the Brahmavaivarta's, a Matsya's, the Ācāramayūkha's) are not a translation source by any statement in the pages. What names the work in Sanskrit is only the Tengyur's catalogues: 84000's Scholar's Room lists Toh 1749 "Analyzing Dreams" with the Sanskrit title *Svapnohana* and Vibhūticandra as translator (the page, read 2026-11-09, gives no Sanskrit manuscript or location); the Derge print's colophon calls him maker of his own translation (svo:p271; svo-authorship-witnesses). The Sanskrit title in the Derge title line is transcribed in Tibetan letters (svo:p268).

So the Svapnohana is, as far as the sources read go, a text without a known Sanskrit manuscript: a text whose series is the Brahmavaivarta's, in a Tibetan translation of about 1200 (claim indian-dream-series-earliest-witness-and-dates).

Doubt: Scheuermann's chapter (SCH, pp. 161–180), which may name a Sanskrit parallel, was not opened: Brill answered HTTP 403 and 405 again on 2026-11-09 for the page and the PDF link.
