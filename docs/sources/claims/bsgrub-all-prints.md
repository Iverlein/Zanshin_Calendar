# The five graves' «བསྒྲུབ» is carved the same in all prints read

The two Zhol-block places of «བསྒྲུབ» on pp. 124–125 (wbz-p124-bsgrub) and the Gser thang reprint (img. 133, p. 125, l. 12, 2026-11-01, «བསྒྲུབ་ཏུ་མི་རུང་བསྒྲུབ་པ་ན») carve the same stack, so in the five graves of pp. 124–125 the fifth is «བསྒྲུབ» in every print read. It is a spelling of the print, not a slip of one setting; whether it names the sinking grave of p. 74 (བསྣུབ) is not decided by the page, but the line of p. 125 sets «བསྒྲུབ་ཏུ་མི་རུང་» ("not allowed to be bsgrub") beside burning (སྲེག) and hiding (སྦ), the same set as p. 124's list.
