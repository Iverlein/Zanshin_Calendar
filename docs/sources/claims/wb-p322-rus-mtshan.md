# WB p. 322: Viśākhā's line reads «རུས་མཚན», not «དུས་མཚན»

# WB p. 322: Viśākhā's line reads «རུས་མཚན», not «དུས་མཚན»

The second line of Viśākhā's verse is «རུས་མཚན་དབང་པོ་མེ་ལྷ་ལྷ» on the Zhol print (WBZ img. 1076, read at 2×), and the first letter has the shape of «རུས་ནི» on the Gser thang reprint (img. 328, in the reading log at 3×). The machine text had «དུས་མཚན». The etexts of the 1996 print and of the Zhol print also have «རུས་མཚན་དབང».

So the line is a clan line like the other verses', not a word for time. Which words are the clan and which the deities is not settled: the English keeps a query.
