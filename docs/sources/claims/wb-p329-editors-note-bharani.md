# WB p. 329: the editors' note on Bharaṇī names no source

The note stands in round brackets in the print's small letters, inside the head of the class of the stable and accomplishing mansions (Gser thang reprint I3CN5029 img. 335): «བརྟན་པའི་དོན་གྲུབ་སྐར་མ་ལྔར་བྲ་ཉེ་འདྲེན་པ་ཕལ་ཆེར་ལ་འདུག་ཀྱང་འབྲས་བུའི་སྐབས་བཞག་པའི་བཞི་འཐད་པར་སེམས།». Most (texts) bring Bharaṇī (བྲ་ཉེ, bra nye) into these as a fifth, but the four set down in the section on results are thought right.

It names no text. "Most" has no noun on the page, and "the section on results" is taken here as this class list itself, the verse then giving four: Maghā, Pūrvaphalgunī, Pūrvāṣāḍhā and Pūrvabhādrapadā. With the note followed, Bharaṇī stands in none of the seven classes, which hold 27 names with Abhijit. Whose note it is, and what "most" stands on, was not searched.
