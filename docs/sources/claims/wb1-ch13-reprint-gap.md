# The Gser thang reprint lacks pp. 167-174 of WB vol. 1

In the Gser thang reprint of WB vol. 1 (I3CN5028) the printed page equals the image minus 7 only as far as p. 166 (image 173); the reprint then jumps to p. 175 at image 174, so it does not hold pp. 167-174. The model almanac's pp. 167-172 (the tail of the 7th to 10th months) are only in the 1996 print (I1KG12906, image = page + 10; images 177-182 are cached), whose boxes are small and soft. The prompt's range 154-171 as images 161-178 is therefore right only for pp. 154-166.
