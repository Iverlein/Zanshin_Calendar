# Langging's table pairs the dragon year with the dog, not the mouse

On p. 186 the table of Langging the red (no. 19) pairs the dragon year with the dog («འབྲུག་ལོ་ཁྱི་ལ»), not with the mouse. On the Gser thang reprint (img. 192, 10x) the syllable has the long left stem of ka and the subjoined ya, unlike the round-headed «བྱི» of the hare's pair in the line above; the Taikhang reproduction (img. 279) carves the same stem; the 1996 etext, the Gser thang etext and a digest's search snippet all read «ཁྱི», and BDRC's search for the line with «བྱི» in that place finds nothing. The table then reads: rat, tiger; ox, sheep; tiger, hare; hare, mouse; dragon, dog; snake, bird; horse, monkey; sheep, horse; monkey, dragon; bird, hare; dog, ox; pig, snake. The Zhol print's crop (img. 897) is too small to tell the letter. Settles question 434.
