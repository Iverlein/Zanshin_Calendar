# A Bhutanese table manuscript (MW26041) repeats KP's boxes 12, 13, 19, 56, 57 and 60 in the same words

BDRC's *Dkar rtsis dang nag rtsis kyi gzhung* (MW26041, a hand-written dbu can manuscript of 594 pages, Thimphu, Kunsang Topgyal; etext IE0OPI1829B6AF, scans I1KG11905, "Astrological and prognosticatory texts from Bhutan") carries the same activity tables as KP's boxes, in the same words, so it is a second witness for the boxes' last lines. Its etext is a poor OCR (syllables dropped, words run together), so it serves for what it prints plainly, not for spelling. The manuscript is modern: its facts are used here, its wording is not copied beyond the few syllables each fact needs (SPEC §8); it is a witness of rank 3, below WB.

What it prints against KP's boxes (etext pages [p375], [p377], [p381], [p408]-[p411]):

- Box 12, the setting-out run: «… འཇིག་ཉེ་ ཕུང་ཟེར་ པི་ལིང་ སའི་འཕུང་བྱེད་ཉིནག་ འགྲོ་མིའི་བདུད་གཅོད་སོགས།» (p. 375): the same run as KP's (kp:i27), with «སའི་འཕུང་བྱེད» and, in the slot where KP's scan is read «ཉི་ནུབ», «ཉི་ནག» (written «ཉིནག»). WB's parallel «པི་ལིང་ས་ཕུང་ནག་པོ་རྒྱུ། ཉི་ནག་བདུད་གཅོད་ལ་སོགས་ངན» has the same order of lords (pi ling, the earth-heap lord, the great black day, the demon-cutting).
- Box 13, the first outing: the print ends the same line as KP, «ཧལ་ཁྱི གཅིག་དཀར་རྭ་བརྒྱད་གདོང་ཐུག །ཁྱད་པར་ཆུང་སྲི་བུ་ཟན་བཅས་ལ་འཛེམ།» (p. 377), with no «མ» before «ཐུག»; the phrase «གདོང་ཐུག་འཛེམ» (the head-on meeting is avoided) also stands at pp. 411 and 427.
- Box 19, peace: the run «… སྡིག བུམ་སྟོང་ ས་བྱ། བདུད་རྩི་ཐུན་མཚམས་སོ། ། ཞག་ནག་ འཕུང་བྱེད་» (p. 381): after «བུམ་སྟོང་ སེ་བྱི» the two words «ཞག་ནག་ འཕུང་བྱེད་».
- Box 56: «… རྒྱབ་ ཕྱོགས་ དབང་མོ་ ཁྲག་སྒོར་ ཅ་མུནྟི་ ཁྱབ་འཇུག་རྒྱུ་དུས་ མཐོང་བརྒྱ་དུས་ནུབ་» (p. 408): the Lady, Khrag sgor, Tsa mundi before the course times of Vishnu, as KP (kp-box56-is-wb-work53-condensed). WB's print has the other order (below).
- Box 57: «མ་རིག་ མིངགཟུགས་ དབུལ་ཉི་ ཕུང་པོ་» (p. 409): the same «དབུལ་ཉི» as KP's box 57 where WB has «དབུལ་པོ་ལག»; in a verse of the same book (pp. 226-227) «དབུལ་ཉི་བར་ཁྱི་གནམ་ཁྱི་སྦྱོར» stands beside a separate «ཉིནག་ཆེ་ཆུང», so «དབུལ་ཉི» is the tradition's own unit.
- Box 60: «རཱ་ཧུ དྲ་ཆེན་ པ་ལིང་ཧལ་ཁྱི … ཀི་ཀང་ དབུལ་ ལོ་ཟླ་ཞག་ནག་ཕུང་ཟེར་སྦྱོར་བྱེད་རྟེན་འབྲེལ་… དོན་བསྟུན།» (p. 410), the OCR garbling the syllables before Rahu into «(འཁྲག་ཉ)ར་ཧུ».

Nothing here is a rule for a date; it shows that KP's differences from WB are the wording of the table tradition and not slips of one cutter.
