# The last name in each cell of p. 133's table of the twelve days is the day's earth lord

The last name in each cell of the upper table of WB vol. 1, p. 133 (rat «གཉན་ཁྲ», ox «གཉན་ལྗང», tiger «བྱ་ཁྱུང», hare «རུས་སྦལ», dragon «བ་དན», snake «ཙང་ཀུན», horse «བྱི་ལམ», sheep «བེ་སྣ» (the print's «བེ་དབང»), monkey «གཟིག་མཇུག», bird «ཧེ་ཐོན», dog «ཐེ་ཁྱིམ», pig «གཉན་བེ») is the name of the earth lord of that day's animal, the same twelve names as WB's own list of the hidden twelve on p. 221 («གབ་པའི་ས་བདག་བཅུ་གཉིས»: «གཉན་ཁྲ གཉན་ལྗང བྱ་ཁྱུང་ག་རུ རུས་སྦལ་སེར་པོ བ་དན་སེར་པོ ཙང་ཀུན བྱི་ལམ བེ་སྣ་ལག་ཆེན གཟིག་མཇུག ཧེ་ཐོན … ཕྱུག་པོ») and as the day-courses of pp. 224–225 («བྱི་བའི་ཉི་མར་གཉན་ཁྲ་རྒྱུ། གླང་གི་ཉི་མར་གཉན་ལྗང་རྒྱུ། སྟག་ཉིར་བྱ་ཁྱུང་དཀར་པོ་རྒྱུ … ཕག་ཉིར་གཉན་བེ་ལ་བབ»). So the ox's name is «གཉན་ལྗང» (the green gnyan), not the machine readers' «གཉན་སྣང» or «གཉན་ལྷང», which the second table's own ox cell («གཉན་ལྗང») and the hidden twelve both rule out; the hare's «རུས་སྦྲུལ» is the tortoise «རུས་སྦལ» spelt otherwise, the monkey's «གཅིག་མཇུག» the leopard's tail «གཟིག་མཇུག». A witness, a Bon students' textbook of black reckoning (*Sgo bzhi mdzod lnga'i yang bcud*, vol. 29, I4PD3282, etext pp. 295–296, a Bon work and so a witness only, nothing built on it), copies the table in this form: seat, harm, name, for the rat «ཆང་རྫ་ལ་གནས། ཆང་མ་ལ་ངན། གཉན་ཁྲ», the ox «བང་བ་ལ་གནས། བྲེ་ཁ་པ་ངན། གཉན་ལྗང», the pig «འཇོར་ལ་གནས། རྐོ་མཁན་ལ་ངན། གཉན་བེ», the dog «ས་ཐེམ་པ་ལ་གནས། རོ་ལས་པ་ལ་ངན། ཐེ་ཁྱིམ»: it too puts the name last in each cell and has the rat's harm on the beer-maker «ཆང་མ», a person. Settles question 460.
