# The 雑書夢合 / 三世相小鑑 prints the table 夢をみてかたらぬ日 too, agreeing with the 万代大雑書

The 雑書夢合／三世相小鑑 (Koizumi ORMK-02344, image 27) does carry a table of the days on which a dream is not told, headed 夢をみてかたらぬ日, one column for each of the twelve months with two or three day branches in kana, and the cells that could be read agree with the 万代大雑書古今大成's table (mdz:p11): this is a second print of the same table, with no slash seen and no closing line read. The print is dated by its colophon to 安永3 (1774) with a reissue of 享和1 (1801). So the table is in two prints, not one (see also eb9:i9).
