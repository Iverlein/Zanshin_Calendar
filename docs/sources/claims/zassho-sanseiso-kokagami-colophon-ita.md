# The colophon of the 雑書夢合／三世相小鑑 reads 新板, with a Kyoto bookseller

The left edge of image 27 of the 雑書夢合／三世相小鑑 reads 安永三午春新板 and 享和元酉春新板, then a Kyoto address (京松原通冨小路東) and a bookseller ending 屋吉右衛門. The character is 板 (printing block), not 刻 as RD364 read it; the sense is unchanged: a block of 1774 reissued in 1801.
