# The table of undreamt days descends from the 拾芥抄's 不語夢日, which gives the reason; the slash is a column break

The Edo table of the days on which a dream is not told (夢を見て語らざる日, mdz:p11, mdz:i234427b, mdz:i183121) has an older source: the entry 不語夢日 of the 拾芥抄 (Shugaisho, a Kamakura-period encyclopedia of court usage), read in the 1906 Kojitsu sosho print (mdz:i772010). The entry gives the twelve months, each with day branches set in a two-column small note, and the reason: on those days, telling a good dream destroys it and a bad dream becomes evil (件日語吉夢、滅成悪夢凶也, read in outline). Some cells agree with the Edo table in set and grouping (months 1, 10, 12), others share most branches but not all, so the Edo table is a descendant with its own variants, not a copy. Because the 拾芥抄 sets each cell as a two-column note too, the slash of the transcription is a column break in the old layout; it carries no second rule in either text. The rule is a rule by month and day branch (a day of the cycle), not by season or date. A twentieth-century book on Heian culture (NDL pid 1127180, p. 185) also cites it as a calendar of days on which dreams are not told; not read here.
