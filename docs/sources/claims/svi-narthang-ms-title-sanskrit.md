# The Narthang manuscript's Sanskrit title reads «སྭ་པ་ནེ་ཀྵ»

On the Narthang manuscript (img. 289 line 3, 9×) the title's four signs are plain: ས with the wa-zur triangle below, པ, ན with ེ above, ཀ with ྵ: «སྭ་པ་ནེ་ཀྵ», as in the Peking print and against the Derge etext's «སྭ་པ་ན་ཨི་ཀྵ». Yigdzin-1's «སྦ་པ་ནེ་ཀྵ» takes the triangle for a ba-sign (moderate).
