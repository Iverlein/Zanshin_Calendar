# Ch. 27: the set of four headed «བརྗེ» is the monk's

The second set of four of ch. 27's reckonings in four (WB vol. 2, p. 23, l. 22, I3CN5029 img. 29, line 22 enlarged 4 times) is headed «དེ་བཞིན་བརྗེའི་རྩིས་སྐོར་བཞི», "likewise the four reckonings of «བརྗེ»", the three words printed with dots beneath as the print marks a head; Yigdzin-1 reads the same. The word is read as printed. Its things are a golden vajra, the crystal of heart-practice and discipline, a silver maṇḍala of veneration and the vase of discipline, and its black end is going begging in the villages: the set is for the monk. The chapter's close names the persons whose luck is cherished as the king, the chief, "mantrin and monk" (སྔགས་བཙུན) and the learned (WB p. 25, same pages), and the sets run king, «བརྗེ», mantrin, Bon priest, young man, minister, noble lady, common woman, child, so that the second set takes the place the close gives the monk. That «བརྗེ» is a spelling of the monk (བཙུན) is not shown by any text; the Sakya and Zhol etexts (OCR) read the word likewise in the begging line.
