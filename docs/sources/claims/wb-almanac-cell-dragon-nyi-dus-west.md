# The model almanac's chart writes «འབྲུག་གྱི་ཉི་དུས། ནུབ་བལྟ།» in a cell: the day-time as an animal with a direction

The model almanac's year charts of vol. 1 (the 1996 print pp. 138-147, the Gser thang reprint I3CN5028 img. 145-147 for pp. 138-140) write in one cell, at the lord's place round the year's animal, a word for the day-time of the animal and its direction: on p. 140, the top chart's right-hand cell ends «…འབྲུག་གྱི་ཉི་དུས། ནུབ་བལྟ།» ("the dragon's day-time; [he] looks west"; read on the scan at 4x for the last line, the first three lines not read), as p. 210's «འབྲུག་གི་ཉི་དུས་ནུབ་ཕྱོགས་ངན» has it. So the almanac keeps the short «X-གི་ཉི་དུས» and a direction for Wangkhyi and has no hour and no day count; it adds nothing to q445. The print's script is a set of its own with invented letters in the small cells, so the cells are a witness to the sense only.
