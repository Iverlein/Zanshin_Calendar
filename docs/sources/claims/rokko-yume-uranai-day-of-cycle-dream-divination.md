# The 夢合長寿鑑絵抄 has a dream divination by each day of the sixty-day cycle (六甲の夢うらなひ), a different table from the days a dream is not told

Image 27 of the Kyoto copy (DIG-KYOT-06268, Ansei 4) sets out one article for each day from the jiazi day on, naming a quarter of the compass and a happening. It is read only in part, so what it says of the days of the table mdz:p11 is not known; it is no table of days on which a dream is not told, and no print reached (RD371: thirteen 三世相小鑑, five 大雑書三世相, the 萬歳大雑書日用寳 images 133-202, two dream books) carries a legend for the gap before the last group of branches of that table.
