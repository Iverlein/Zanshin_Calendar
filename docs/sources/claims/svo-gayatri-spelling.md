# The Gayatri's name in the Svapnohana is ga ya tri in Peking

In the Peking print the Gāyatrī's name is «ག་ཡ་ཏྲི» with ཏྲི (ta with subjoined ra and the vowel i) on a clear scan, as the Derge etext and the Dpe bsdur ma text have it; Narthang reads it the same by eye with less certainty. The spelling is settled as «ག་ཡ་ཏྲི» (Sanskrit gāyatrī) by Peking and the two etexts; the remedy was never in doubt.
