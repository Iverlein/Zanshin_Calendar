# The first circle's broken syllable is the luck, «klung gso 'dzugs»

The first circle's luck remedy (WB vol. 2, p. 4, l. 7), broken on the 1996 scan and the reprint, is «ཀླུང་གསོ་འཛུགས» on the Zhol blocks, setting up the restoring of the luck (ཀླུང, klung); Yigdzin-1 reads the same on the Taikhang.
