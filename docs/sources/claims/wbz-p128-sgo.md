# The fifteenth's heading reads «sgo dbye» on the blocks

The heading of the fifteenth examination (WB vol. 2, p. 128) is «…སྒོ་དབྱེ» on the Zhol blocks, with no ma: the door is opened, and the 1996 «སྒོམ» is a slip of the typesetting.
