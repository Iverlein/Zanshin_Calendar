# The 7th head's weekday line has 3 twice and no 4; the 10th's reads 5 1 3 / 6 / 0 / 2 4

Second pass by eye, 1996 print (RD202, 2026-11-08). The 7th month head's weekday line (p. 167, img. 177) gives dar 0, 6; gud 5; skyod 2, 3; zhud 1, 3. The second figures of skyod and zhud are the same glyph side by side at 12x, so the line has 3 twice and no 4: one is a misprint or a worn 4. The 10th month head's line (p. 171, img. 181) gives dar 5, 1, 3; gud 6; skyod 0; zhud 2, 4, the seven weekdays once each, as in the 8th, 9th, 12th and 1st heads. This settles the three stacked figures after dar of the 10th head that the first pass left open.
