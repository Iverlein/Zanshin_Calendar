# BDRC's search finds no other list of the thirteen blades (question 281)

BDRC's full-text search (2026-11-01, headed work browser) for the thirteen kinds of blade of the seventh examination (p. 73): «གྲི་རིགས་བཅུ་གསུམ» and «ལྟོང་དམར་ཆུ་གྲི» have one hit each, in the 1996 etext (p. 73's own lines); «ཐོག་གྲི་རྐུན་པོ» and «སྤྲེ་ཤལ་བཟེད་རབས་ཆད» none; so no other manual among the etexts BDRC indexes lists the thirteen blades or the thirteen kinds of corpse under these names. Question 281 stays as the notes leave it («མི་གསལ་ནག་ནོག་ཅན», unclear and tangled).
