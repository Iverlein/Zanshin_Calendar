# WB p. 322: Anurādhā's good list has rites for long life

Anurādhā's good list has «ཚེ་སྒྲུབ་ཞིང་ལས་ས་བོན་གདབ» on the Zhol print (WBZ img. 1077, a three-level stack at 3×), and the Gser thang reprint is logged the same (img. 328). The machine text had «ཚེ་སྣུབ», which the English had passed over. So rites for long life (ཚེ་སྒྲུབ, tshe sgrub) belong in the list beside field work and sowing. The passage stays machine for other words; this one was read on the Zhol.
