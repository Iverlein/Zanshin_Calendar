# The thirty's element: the same phrase as the circles, and the year-horse

The phrase that picks the thirty's pairs is the one that starts the circles. WB's thirty (vol. 1, p. 453) begins each pair from the years "in agreement with the element of the one reckoned" («བརྩི་བྱའི་ཁམས་མཐུན»); the circles (vol. 2, p. 3) begin from "the enemy of the element of the one reckoned" («བརྩི་བྱའི་ཁམས་ཀྱི་དགྲ»). The notes gloss the circles' phrase as «བརྩི་བྱའི་ཁམས་སྟེ་དབང་ཐང་གི་དགྲ», "the element of the one reckoned, that is, the enemy of the power" (vol. 2, p. 533). The same words in the same author's two chapters are most simply read the same way: the element is the power's, the element of the year's own name.

For the thirty the notes say «ལོ་རྟ་དང་ཁམས་མཐུན་པའི་བྱི་གླང་སོགས» (p. 532, read again on the reprint 2026-10-25): from the rat and ox "in agreement with the element of the year-horse (ལོ་རྟ, lo rta)" of the one reckoned. The same notes use «ལོ་རྟ» for a lord's, a horse owner's, a son's and bride's, a house owner's and an asker's year, so it is a person's or thing's birth year; the element in agreement with it is the year's element, which is its power. Inference from the wording; no text says "the power" for the thirty. Not excluded: the pair's two years also share the body element.
