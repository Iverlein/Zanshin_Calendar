# The Narthang manuscript's Amoghasiddhi line «བྱ་ཤ?་ཏེ…» is not settled

On the Narthang manuscript (img. 290, end of line 2, with «ཕོ་ཉར་གཏོང» opening line 3) the line ends བྱ, a ཤ-headed syllable whose lower sign is a smear, ཏེ with ེ above, and one or two more groups at the frame's edge (a long diagonal and an oval stack, possibly «འུ»). Yigdzin-1 on 16 windows reads «ཤན», «ཤད», «ཤར», «བཤན»/«བསྟན» and «ཏེ»/«ཏེའུ»: no stable reading. The manuscript is therefore no witness for the Derge etext's «བྱ་ཤར་ཏེ་རུ» nor for the Peking's «བྱ་ཤིང་ཏེ…»; no ི is seen over the second syllable (moderate). q835 stays open.
