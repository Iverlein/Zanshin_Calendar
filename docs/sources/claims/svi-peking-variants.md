# The examination of dreams in the Peking print

Peking (W1KG13126 vol. 46 pp. 309–312, I1KG13215 img. 309–312) agrees with the Derge text in the places read by eye. Differences: the Sanskrit title «སྭ་པ་ནེ་ཀྵ» for «སྭ་པ་ན་ཨི་ཀྵ»; «དེད» (not «དེ»); «ཕྲོགས» (not «གྲོགས»); «རྐྱལ» (not «རྒྱལ»); the Amoghasiddhi line «བྱ་ཤིང་ཏེ…ཕོ་ཉར་གཏོང» (the etext «བྱ་ཤར་ཏེ་རུ»), unsettled by eye.
