# P. 98's «bkra ngo» is «bkra ro» on the blocks

In the readings of the corpse's place by the pebble (WB vol. 2, p. 98, l. 5), the Zhol blocks carve «གཅིག་དཀར་སྟེང་དུ་བཀྲ་རོ་བཟང», a speckled corpse (བཀྲ་རོ, bkra ro), like every following line's «རོ»; the 1996 print's «ངོ» is a slip of the typesetting.
