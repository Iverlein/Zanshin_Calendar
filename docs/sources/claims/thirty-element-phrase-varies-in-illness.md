# The phrase brtsi bya'i khams in the illness reckoning changes element by examination

# «བརྩི་བྱའི་ཁམས» in the illness reckoning's thirteen is not one fixed element

In the illness reckoning's opening examinations (WB vol. 1, pp. 417–419, the etext p. 427–429; health.md quotes them) each examination starts "from" an animal by a relation, in the phrase of the circles: «བརྩི་བྱའི་ཁམས་ཀྱི་དགྲ་སྟག་ནས། དུ་ལོན་ཐུར་…», "from the tiger, the enemy of the element of the one reckoned, down by the years lived". The same start animal, the tiger, stands under four relations in four examinations: enemy (the king's seat, the second), mother (the third, the cap and dust), friend (the fifth), son («བརྩི་བྱའི་ཁམས་ཀྱི་བུ་སྟག་ནས», the twelfth, the wind). One element has one enemy, one mother, one friend and one son, and these four are four different elements: so the element «ཁམས» of the one reckoned changes from examination to examination there, each presumably the element of the aspect examined; the bare phrase does not fix which element on its own.

For ch. 26 this cuts two ways: the phrase alone cannot decide between the power, the life force and the rest (question 259 stays open on the words), but the thirty's fifteen pairs run own, son, friend, enemy, mother round one element and are read with one element for all fifteen (the printed list names its relation in each line), as the notes' «ལོ་རྟ་དང་ཁམས་མཐུན» says, so for the thirty one element serves, not one per check. Inference from the wording; the examinations were read in the etext and the pool's quotations (health.md), not again on the scan for this claim.
