# The thirteenth gate: horse in the heading, bird in the result, on the blocks

The heading of the thirteenth gate (WB vol. 2, p. 170) is «འཕུང་རྟ་རྔ་ཞོན» on the Zhol blocks, ར over ཏ, as the 1996 print. The result line is «ཚུར་བཅད་འཕུང་བྱ་རྔ་ཞོན་ངན», bird, on the Taikhang reproduction (illegible on WBZ). So the blocks themselves name the horse in the heading and the bird in the result: the disagreement is WB's, not the 1996 setting's.
