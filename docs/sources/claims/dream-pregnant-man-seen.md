# A pregnant woman dreaming of a man

Image group: the dreamer ill. Read by 1 text: Four Tantras (for a sick dreamer).
Offered only when the dreamer is ill: every row is a reading for a sick dreamer (the Four Tantras above WB ch. 25).
The word that was unsettled, དག, is settled by two commentaries (RD229: again and again, a plural or frequency marker); this image is no longer listed apart in dream-unsettled-words.
