# The twelve strip charts of WB vol. 1 ch. 13: order on the Zhol print and the 1996 print

The Zhol print (I1KG1710) holds twelve strip charts on three leaves, img. 151 to 153, four to a leaf, each with an animal woodcut in a wide middle strip and cells above, below and at the sides. The animals run in the order of the cycle from the rat: rat, ox, tiger, hare; dragon, snake, horse, sheep; monkey, bird, dog, pig. The 1996 print's pp. 142 to 147 carry twelve strip charts of the same kind in the order tiger, hare, dragon, snake, horse, sheep, monkey, bird, dog, pig, rat, ox. Seen by eye only; the cells' words of neither print are settled (see wb.1:p142 to wb.1:p147, machine text).
