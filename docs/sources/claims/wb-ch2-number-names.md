# WB ch. 2 names the numbers from one to the great numbers, ten times each step

In the order of p. 20 (machine reading): the single numbers one (གཅིག), ten (བཅུ), hundred (བརྒྱ), thousand (སྟོང), myriad (ཁྲི), hundred-thousand ('bum), sa ya, bye ba, dung phyur; then the great numbers ther 'bum, khrag khrig, rab bkram, gtams, dkrigs, mi 'khrugs, khyad 'byin, spang rten, ded 'dren, mtha' snang, rgyu rig, 'od mdzes, dbang po, legs 'byin, rtogs 'gro, 'bying rdul, rgya rtags, stobs 'khor, brda shes, rnam byung, stobs mig, khyad 'byin (again), byams pa, snying rje, dga' ba and btang snyoms, with the last called 'without count'; each is joined to the next by ten-fold. The numerals printed in brackets beside the names are not read (the two scans give different figures from the tenth on), so no value is stated here.
