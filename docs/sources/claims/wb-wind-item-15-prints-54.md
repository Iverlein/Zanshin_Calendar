# Item 15 of the forty kinds of the birth wind is printed «ང་བཞི» (54) on every print found; the run asks for 50

Item 15 of the forty (son one, mother three; wb.1:p342, on the Gser thang scan, every figure read) is printed «བུ་གཅིག་མ་གསུམ་ང་བཞི་བརྒལ», the same figure as item 13, friend three and own two; the run of the forty falls by two years a step (58, 56, 54, 52 for items 11–14 and 48, 46, 44 for 16–18), so 50 is missing at 15. BDRC's etexts of the 1996 print, the Gser thang reprint, the Zhol print (the OCR of image 445) and the Sakya Centre print (full-text search for «ང་བཞི་བརྒལ», 2026-11-01) all print «ང་བཞི» at item 15; none prints fifty («ང» alone, «ལྔ་བཅུ»). No other manual read repeats the forty (the Bhutan collection, UT, the G.ya' sel etexts: «ང་དྲུག་བརྒལ», «ཞེ་བརྒྱད་བརྒལ» nowhere). So the print's figure stands as printed, a slip either of WB's own hand or of the blocks' common source; a build that lists the forty shows 54 as printed and may note that the run asks for 50.
