# WB ch. 2 gives the full multiplication table of the digits one to nine, and its values are correct

The verse of pp. 20–21 (machine reading) states, for each digit from nine down to one, its product with each digit not larger than itself, each pair written as '9 1 1 9 9' (the numbers, then the product), from nine nines eighty-one to one one one. All entries read in the text agree with ordinary arithmetic (9×9=81, 8×7=56, 7×6=42, 6×5=30, 5×4=20, 4×3=12, 3×2=6, 2×2=4, 1×1=1 and the rest). No entry is wrong or in doubt in the machine text.
