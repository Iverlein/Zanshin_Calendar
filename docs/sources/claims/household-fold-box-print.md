# The box over the fold on Mipham's own print

The box over the fold's fourth and fifth columns (vol. 2, p. 491): on Mipham's own print (I2029 img. 653, the fold's table at the right of the page, at 12×) the box carries about six syllables of which only the first and the last stacks are distinct (the first with ཕྲེ, the last with ོར), the rest blotted into a bar; the Chengdu typeset's «ཕྲེང་བ་འདི་གཉིས་དོར», "these two rows cast off", fits the length and both ends. «རྡེལ་ཕྲེང་གསུམ» and the box stay as read (question 320 narrowed: the box agrees with the typeset, not settled on the print).
