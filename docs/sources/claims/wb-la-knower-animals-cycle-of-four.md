# The la-knower's animals in p. 133's second table run tiger, pig, monkey, snake

The la-knower's animal in the cells of the second table of p. 133 (the time's cell, the same for every day) runs through the twelve times in a cycle of four: tiger (midnight), pig (the ox's time), monkey (the tiger's), snake (the hare's), then tiger (the dragon's), pig (the snake's), monkey (the horse's), snake (the sheep's), [tiger expected for the monkey's time; the cell reads monkey], pig (the bird's), [monkey expected for the dog's; not legible], snake (the pig's). RD78's "monkey for the sheep and pig" is a slip of «སྤྲེལ» for the cells' «སྤྲུལ» (a spelling of «སྦྲུལ», snake); read so, ten cells fit the cycle, one reads against it and one is illegible. A Bon students' textbook (I4PD3282, etext p. 297, a witness only) lists the same animals by the time for the dragon's (tiger), snake's (pig), horse's (monkey), sheep's (snake), hare's (snake), tiger's (monkey), ox's (pig), rat's (tiger), pig's (snake). So the animal follows the position of the time in the day, not the day's animal; why tiger, pig, monkey, snake (the four corners of the seasons' first months) is not stated. Narrows question 459.
