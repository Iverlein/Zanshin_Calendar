# The two Tokyo Gakugei Daizassho prints (1780, 1828) show no day table for a dream on the sheets

In the two Tokyo Gakugei prints of the Daizassho (An'ei 9 = 1780, bid 100408974, 27 images; Bunsei 11 = 1828, bid 100408973, 28 images), seen leaf by leaf on contact sheets of 700 px and the last text leaf of each at 3000 to 5000 px, no leaf carries a table of twelve month columns of day branches such as the one of the other prints, and no slash. The 1780 print has, on image 24, a boxed item that opens with the character for dream and runs about ten columns (mdz:i100408974); the 1828 print has the same book (the same pictured leaves on images 23-24, the same last text leaf). The leaves of running text were not read letter by letter, so a dream table inside the columns is not excluded; the colophon of the 1780 print names the Nishimura-ya publisher at the foot of image 25.
