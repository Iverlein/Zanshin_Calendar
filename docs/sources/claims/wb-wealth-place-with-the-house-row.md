# The wealth's place is read with the house's row

Mipham's notes (typeset p. 491) name the layers in order: the god's places with the last pebble, then the people's place, then «བཞི་ཁྱིམ་དང་ནོར་ས», the house's four and the wealth's place (ནོར་ས, nor sa), then the enemy's place under all the rows. The wealth's place is thus not a row of its own: it is read with the house's row, whose first three pebbles and the last are the four. WB's own count (p. 386, «ལྷ་ས་མི་སར་རེ་རེ་སྟེ། ཁྱིམ་ས་དག་ལ་གཉིས་གཉིས»: one each in the god's and the people's places, two in the house's; BDRC's full text finds the verse only in WB's prints and KD's copy) is how many of each row's pebbles bring it; which they are, neither WB, the notes nor the manuals say. What colour reads there is told nowhere apart from the house's place's own readings.
