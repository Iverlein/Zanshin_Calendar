# Ch. 13 Zhol ox chart: same layout and set word as the rat chart

On the Zhol leaf img. 151 the second strip chart is the ox, laid out as the rat chart: a top row with a wide empty cell, tiers of side cells with a slim empty one, a bottom row; se bdud (སེ་བདུད) opens a top cell and a bottom cell. 4x crops of the cursive hand settle that word and the cell plan only; the other syllables stay unsettled, so the next reading needs 6x strips one cell at a time.
