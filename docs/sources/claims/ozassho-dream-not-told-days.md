# The days of the month on which a dream seen is not told (大雑書)

The same 大雑書 has the one dream rule found that is tied to the calendar: a table "days on which a dream seen is not told" (夢を見て語らざる日), twelve cells, one for each month, each naming day branches of the sexagenary cycle (month 1: goat, monkey / dog; month 2: rooster, monkey / snake; month 3: goat, horse / boar; months 4 and 5: horse, ox / hare, boar; month 6: rat, ox / boar; month 7: rat, ox / dragon; months 8 and 9: tiger, dragon / rat, boar; month 10: dragon / snake; month 11: monkey, goat / dog; month 12: horse, goat / boar), and the closing line that on the days above a dream, whether good or bad, is not told. The rule does not read the dream: it says to keep silent about it on those days. What the slash inside each cell divides is not explained on the page. The page says nothing of which calendar the months are, and the table's source in older 大雑書 was not traced.
