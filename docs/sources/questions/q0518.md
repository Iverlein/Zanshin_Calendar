# The body's friend «བེ་ལུག» or «བུ་ལུག» on the Zhol block

The Zhol print's etext (I1KG1710 p. 433) reads «བུ་ལུག» (a lamb) for the body's friend where the 1996 print and the Gser thang reprint read «བེ་ལུག»: which does the Zhol block carry, and is the body's friend the young of the herd?

## Answered 2026-11-06

RD175 (2026-11-06): Zhol img. 433 line 3 reads «གྲོགས་ཀྱིས་བེ་ལུག་ས་རུ་བལྟ», the ེ sign visible at 8×; the Taikhang (img. 450) also reads བེ. The Zhol etext's «བུ་ལུག» is a misreading, so the body's friend is བེ་ལུག.
