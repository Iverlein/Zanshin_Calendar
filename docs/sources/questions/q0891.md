# Does the cows' line of the Aṣṭāṅgahṛdaya (Śārīrasthāna 6.63) read gosarge in the older manuscripts too, or gomārge as in some prints (the Śabdakalpadruma's gomarge)?

Kunte's apparatus was not read (RD295).


Narrowed (inv-i, 2026-11-13): seven prints now read give «gosarge»: the six of RD312 and Kunte's 1880 print with Aruṇadatta (text layer, lemma «gosarge gavāṃ mokṣakāle»), and the Derge Tengyur's Tibetan translation renders the line with «nang par», the morning, the time and not the cows' path (ahd:p257, claim ahd-nang-par-renders-gosarge). No manuscript was seen; «gomārge» is found in no print or witness read.
