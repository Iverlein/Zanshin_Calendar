# Is «པདྨ་ཀ་ར» on p. 443 Padmasambhava

On p. 443 (img. 449) the last line names the Indian teacher who came to Tibet with the abbot Śāntarakṣita as «པདྨ་ཀ་ར» (MITRA) where Yigdzin-1 has «པཊྚཱ་ཀ»; is this Padmasambhava (Padmākara)? (RD84)

## Answered 2026-10-31

**Answered 2026-10-31 (RD84, eye pass, [corpus/wb/ch35.md](../corpus/wb/ch35.md#wb-2-p443)).** The print has «པདྨ་ཀ་ར» (Padmākara), broken over p. 443's last two lines as «པདྨ་ཀ་ / ར་ལ་སོགས་པ», not Yigdzin-1's «པཊྚཱ་ཀ»: on the scan (img. 449), enlarged four and five times, the stack is ད over མ. The same name opens p. 442 («རྒྱལ་དབང་པདྨ་ཀ་ར་ཡིས།», the one who hid the Four Tantras as treasure). The name is read on the page; that Padmākara is Padmasambhava rests on the name alone.
