# «མགོ་མཇུག་ལོག» in the benefits texts

Does «མགོ་མཇུག་ལོག» in the Gangtok print and 'Jam dbyangs don yod mean a wheel set upside down, a roll wound the wrong way, or a wheel turned the wrong way?

RD171 (2026-11-06), narrowed: «མགོ་མཇུག་ལོག» is 'reversed, upside down' (Ives Waldo), elsewhere of an object or letter inverted, including a dhāraṇī put into a support head-and-tail reversed; the 1991 print has it too. Whether it means the roll or the manner of turning is not said; no text says the roll is wound that way.
