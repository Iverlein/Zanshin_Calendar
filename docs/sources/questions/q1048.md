# In the lines «བྱ་བ་དུས་ཀྱི་རིམ་པ་ཉིད» (mmk.1:p400-401) is the Sanskrit's word «krama» (order) or «sama» (equal), and does «རྨི་ལམ་ཞེས་བྱ་ཡོད་པ་སྤངས» mean all dreams are set aside or only the «dream-named» kind?

RD372.

## Narrowed 2026-11-13

The first half is answered by the claim mmk-rim-pa-is-krama-not-sama (RD395): «རིམ་པ» is krama, order; «sama» is «མཉམ་པ». The second half stays open: «ཞེས་བྱ་ཡོད་པ» is «the so-called», which leans to the dream-named kind only being set aside, and no commentary on the lines was found. In the Derge volume the same twelve signs and the true-dream pages (mmk.1:p403) follow at once, which also speaks against all dreams being given up.

## Narrowed 2026-11-14

The first half is answered by q1136: the Sanskrit of Gaṇapati Śāstrī's edition (GRETIL keying, mmk.2:p149b) reads «kriyākālasamaś», sama, not krama. For the second half the same verse gives a new fact: it reads «svapnākhyaṃ sattvavarjitam», and the Tibetan renders it word for word: «ཞེས་བྱ» is ākhya ("called"), «ཡོད་པ» stands where the Sanskrit has sattva, «སྤངས» is varjita. So the pāda says "the so-called dream (is) devoid of being (sattva)", a statement about what the thing named dream is, and not a rule that all dreams are put aside; it does not set aside a dream-named kind among others either. The doubt: sattva is "being, existence" or "a living creature", and a commentary was not found to say which (the exact phrase «རྨི་ལམ་ཞེས་བྱ་ཡོད་པ་སྤངས» has the same two hits as before, BDRC search of 2026-11-14), so the reading rests on the Sanskrit's word order and not on a gloss.
