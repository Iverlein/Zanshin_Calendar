# Does the Sanskrit page of the Mañjuśrīmūlakalpa read kramaś or samaś

The Tibetan རིམ་པ is krama; the IA OCR reads «क्रियाकालसमशरैव» and ch. 22 has «एष कालक्रमो योगे»; read in a machine text layer, not on a page image.

## Answered 2026-11-13

The Sanskrit reads samaś. GRETIL's keying of Gaṇapati Śāstrī's edition has «svapnākhyaṃ sattvavarjitam / kriyākālasamaś caiva nirdiṣṭas tattvadarśibhiḥ» (verse 15.46; passage mmk.2:p149b), so the machine text layer's «समश्» was right in its letters. The Tibetan «རིམ་པ» is krama in the lexica, so the Tibetan translators read or rendered otherwise than this edition; without the manuscripts it cannot be told whether their Sanskrit had krama. claims/mmk-gretil-reads-kriyakalasama-verse-15-46.md. The edition's text, an etext of a modern print, not a page image.
