# Does the Sanskrit page of the Mañjuśrīmūlakalpa read kramaś or samaś

The Tibetan རིམ་པ is krama; the IA OCR reads «क्रियाकालसमशरैव» and ch. 22 has «एष कालक्रमो योगे»; read in a machine text layer, not on a page image.
