# The element of the one reckoned in each illness examination

In the illness reckoning's opening examinations (pp. 417–419) «བརྩི་བྱའི་ཁམས་ཀྱི» takes a different element in each examination (the tiger is enemy, mother, friend and son in four of them). Which element of the one reckoned does each examination take, and is it the element of the aspect examined?

RD177 (2026-11-06), narrowed (etext): each examination's element is a relation of the reckoned's own element (enemy, mother, friend, own, son tiger/hare; 1, 10, 11, 14, 15 and 16 start from the sky year), not the aspect's element; the Moonbeams' fixed signs are these relations for a person of wood. The 4th point differs: WB 'agreeing in power', LT son.
