# Which three watches does WB vol. 1 p. 17 mean by the night's name «ཐུན་གསུམ་ཀུ་མུད་བཞད་རྣམས», against four watches by night on p. 101 and vol. 2 p. 403?

Does the name rest on the Indian three-watch night?


Narrowed (RD287, 2026-11-10): on the reprint and the 1996 print «ཐུན་གསུམ་ཀུ་མུད་བཞད» is one epithet in a run of the night's names closed by «རྣམས་སོ», not a count of watches; the verse counts none (wb.1:p17c).
