# In the thirty-part chart (kd.3:p129-130) the Kun 'dus etext prints the left row of numbers for the equal houses as 5, 5, 8, 7, 5 although it says «reversed». Is it 5, 7, 8, 5, 5? The author's example (27 = Mars) fits the reversed stretches.

RD369.

## Narrowed 2026-11-13

The etext's 5, 5, 8, 7, 5 is not shown to be a slip: it can be the laying order from the foot of the column, and then the cells hold 5, 7, 8, 5, 5. The author's example (27 = Mars) fits both readings, so it does not decide. The grid must be read on the print (kd.3, printed p. 129; the loaned scans were not opened).
