# The thirteen kinds of blade

The notes (p. 504) call the thirteen kinds of blade «མི་གསལ་ནག་ནོག་ཅན», unclear and tangled, and leave "which the last three are" to be examined. Does another manual (LT, UT, the Bhutan collection) list the thirteen blades?

**Narrowed 2026-11-16 (inv-d).** The thirteen blades are WB's own list (p. 73, the print's numbers 1 to 13, read in the pool). BDRC phrase search: «ཐལ་ཤལ» 12 hits (WB's etexts and Bon and other senses), «དམེ་གྲི་ཁ་བསུབས» 1, «ཤང་དཀར་གནམ་ཐོག» 2, «གྲི་ཁྲག་རྒྱལ» 3. The only other witness is the *Do shal* to the *Vaidurya dkar po* (MW2PD17386_D19206), which quotes the root's lines for 8 to 13 in the same words («bdud med khyags gri grod med dang // bsubs gri g.yen med ces pa dang // 'gags gri bdud med phung stod med // gri khrag rgyal gri dangs gri'o»); it is a commentary on the same text, so not an independent list. «gri khrag rgyal» in the Fifth Dalai Lama's rite of the twelve *brtan ma* (MW1PD107937) is a weapon among «ral gri khrag rgyal zor ba mda'», not a kind of death. The last three (the blade without upper body, the blood-king, the clear blade) are not explained anywhere found.
