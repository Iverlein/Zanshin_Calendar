# In the Tohoku 夢判事 (THKK-22631, image 35) and the Koizumi copy, are the cursive middles of the ten cells' second lines («墨ゆく…») the same words? A reader of cursive kana is needed.

Raised by the 2026-11-13 investigation c; see the question's cited passages.

## Narrowed 2026-11-14 (inv-zzz)

Image 35 of the Tohoku copy (THKK-22631, kokusho bid 100445304, 4000 px, microfilm) was laid beside image 34 of the Koizumi copy (ORMK-00651, bid 100276036, 4000 px). Both give the same ruled page: five cells above and five below in the same order (寅, 辰, 午, 申, 戌; 卯, 巳, 未, 酉, 亥), the same seal-script heads, the same line breaks in every cell, the same furigana beside 悪夢, 是 and 門, and the same box at the left edge. The cursive of every cell has the same stroke shapes in the two, cell by cell, including the cells with a kana gloss (辰: 門, 未: 房 with the gloss and 門). So the two are one block, and the middles cannot differ in words; this is a comparison of shapes, not a reading. The middles of the second lines were not read letter by letter here either, and nothing in this record changes mdz:i65134's marks of doubt.
