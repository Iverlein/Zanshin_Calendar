# The snake's «སྦོ་སྨད» on p. 122

Which mansion is the snake's «སྦོ་སྨད» (sbo smad) of p. 122, when no list of second names has it?

RD180 (2026-11-06), narrowed: the 1996 etext (img. 205, p. 197) has «ལྟོ་བ་མཚན(༥)། །ཡང་ན་ལྟོ་བ་སྦོ་སྨད་ཅེས། །འདི་གཉིས་སྟོད་སྨད་རིམ་པ་གཅིག»: «སྦོ་སྨད» is a name for the lower part of the belly; the passage does not number it as a mansion.
