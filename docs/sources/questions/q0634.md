# The snake's «སྦོ་སྨད» on p. 122

Which mansion is the snake's «སྦོ་སྨད» (sbo smad) of p. 122, when no list of second names has it?

RD180 (2026-11-06), narrowed: the 1996 etext (img. 205, p. 197) has «ལྟོ་བ་མཚན(༥)། །ཡང་ན་ལྟོ་བ་སྦོ་སྨད་ཅེས། །འདི་གཉིས་སྟོད་སྨད་རིམ་པ་གཅིག»: «སྦོ་སྨད» is a name for the lower part of the belly; the passage does not number it as a mansion.

## Looked at 2026-11-16 (inv-u)

Narrowed, no mansion found. The same p. 122 table stands in the Bhutan anthology *Dkar rtsis dang nag rtsis kyi gzhung* (MW26041, etext I1KG11905, p. 524-525, open): «འབྲུག སྦོ་ལ་གསོན་པོར་ཆགས་ཆེ་མང་། … སྦྲུལ སྦོ་སྨད་ལ་གསོན་པོར་ཆགས་ཆེ། … རྟ མཆུའམ་གྲེར། … ལུག བྱི་བཞིན་ལ», so «sbo smad» is no misprint of WB's print and sits there as dragon «sbo», snake «sbo smad». The same volume (pp. 228, 242) uses «སྦོ་སྟོད» and «སྦོ་སྨད» as the upper and lower belly of the sky dog («གྲེ་བ་སྦོ་སྨད་མཚན་མ་མཇུག», «ཇིང་པ་སྦོ་སྨད»), with no mansion name. So «sbo» is the belly in the sky dog's body and the mansion «དབོ» (dbo) of the dragon is in the same spelling; whether the snake's is the lower part of that mansion's two stars or the next one (Uttara Phalgunī, «me bzhi») no text says. Searches: «དབོ་སྨད» 2 hits (a song-biography and a Buddhist logic commentary, «dbo smad 'dzin» in a different sense), «སྦོ་སྟོད» 9 hits (WB, the sky dog texts), «དབོ་སྟོད་དབོ་སྨད» 0, «རུ་སྦོ་སྨད» 0, «སྦོ་སྨད་ལ་གསོན་པོར» 1 (the Bhutan anthology above).

**Narrowed 2026-11-06 (sweep from RD180).** The 1996 etext (p. 197) has «ལྟོ་བ་མཚན། །ཡང་ན་ལྟོ་བ་སྦོ་སྨད་ཅེས།»: «སྦོ་སྨད» is a name of the lower part of the belly, and the passage does not number it as a mansion. The Bhutan anthology (MW26041, pp. 524-525) has the same table; no mansion found.
