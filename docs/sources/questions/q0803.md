# Is the Sakya Paṇḍita attribution on SKP's first text right, given its colophon names Kun dga' rgyal mtshan dpal bzang po?

The title page and the colophon differ.

## Answered 2026-11-10

Answered by RD315 (2026-11-10): the colophon formula «shAkya'i dge slong kun dga' rgyal mtshan dpal bzang po» is Sa skya Paṇḍita's own full name and signature in the Sa skya bka' 'bum etext (47 BDRC hits, 4 in that etext), so the title page and the colophon name the same man; that he wrote the text is the manuscript's claim only, a title search finds nothing; the colophon's cursive itself stays unread on the scan.
