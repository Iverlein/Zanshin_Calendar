# Does the Peking print's «བྱ་ཤིང་ཏེ…ཕོ་ཉར་གཏོང» in Advayavajra's Amoghasiddhi signs, against the Derge etext's «བྱ་ཤར་ཏེ་རུ», name a bird, and what is its last syllable?

Yigdzin-1 reads «བྱ་ཤིང་ཏེའུ».

## Answered 2026-11-14

A bird, and its last syllable is «ཏེའུ» (te'u). The Peking line on the scan (svi:p310b) opens with «བྱ» (bird) and ends «ཏེའུ» with the verb «ཕོ་ཉར་གཏོང»; the Dpe bsdur ma's note gives the Peking as «ཤིང་ཏེའུ», agreeing. The ending «ཏེའུ» is the diminutive that closes Tibetan bird names, and Steinert's dictionaries have «bya shang shang te'u» as a headword (Ives Waldo "shang shang bird"; Tshig mdzod chen mo "like bya shang shang"), so the Peking's «བྱ་ཤིང་ཏེའུ» is a bird's name of the same make, the middle syllable «ཤིང» (the ང the eye holds only moderately) most likely a miswritten «ཤང». The Derge's «ཤར་ཏེ་རུ» ends in «རུ», which ends no bird headword found; see q913 for the name.
