# What are the «གཉན»-kind last names ending each cell of the upper table of WB vol. 1 p. 133

In the upper table each cell ends with a name of the «གཉན» kind (rat «གཉན་ཁྲ», ox «གཉན་སྣང», pig «གཉན་བེ», and for the other animals a name without «གཉན»: «བྱ་ཁྱུང», «རུས་སྦྲུལ», «པ་དན», «ཙང་ཀུན», «བྱི་ལམ», «བེ་དབང», «གཅིག་མཇུག», «ཧེ་ཐོན», «ཇཻ་ཁྱིས»): what are these names, and is the earth lord named by them?
