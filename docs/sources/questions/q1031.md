# How does the Sngags rim chen mo's «the first three watches are not certain, so the fourth is used» come from the root tantra's verse: is it Tsong kha pa's inference from the three humours and «true», or does a commentary on the Mañjuśrīmūlakalpa say it?

RD370.

## Answered 2026-11-10

RD372: Tsong kha pa's reason for using only the fourth watch is not in the verse but not his invention: the same wording is in Kun dga' rin chen (search snippet only, the volume answers 403), and the Rgyud sde kun btus pp. 460-461 reads the first watch mixed with the day's habits, the second and third deep sleep so that no dream comes, and the last, dawn watch very clear and so examined; Shes rab 'od zer says the same of the last part of the night's four. No commentary on the root tantra itself (Bu ston, Mkhas grub rje, Rong zom, Sa skya) was found for the verse.
