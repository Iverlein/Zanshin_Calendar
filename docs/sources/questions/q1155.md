# Is the Dream Tārā practice of img. 75 the work whose text stands in this file's first passage

By Candragomin's pupil, translated by Sugataśrī and Byams pa'i dpal.

## Answered 2026-11-14

Yes, by title, maker and translators word for word. The colophon of the text quoted in svo:p177-179 (Derge Tengyur vol. 28, the Dream Tārā sādhana) reads «རྨི་ལམ་སྒྲོལ་མའི་སྒྲུབ་ཐབས་སློབ་དཔོན་ཟླ་བའི་བཤེས་གཉེན་གྱིས་མཛད་པ་རྫོགས་སོ། །རྒྱ་གར་གྱི་པཎྜི་ཏ་སུ་ག་ཏ་ཤྲཱི་དང་། ལོ་ཙཱ་བ་བྱམས་པའི་དཔལ་གྱིས་བསྒྱུར་བའོ». The Narthang catalogue line of img. 75 (svo:i75) is «རྨི་ལམ་སྒྲོལ་མའི་སྒྲུབ་ཐབས་སློབ་དཔོན་ཟླ་བའི་བཤེས་གཉེན་གྱིས་མཛད་པ། པཎྜི་ཏ་སུ་ག་ཏ་ཤྲཱི་དང་། ལོ་ཙཱ་བ་བྱམས་པའི་དཔལ་གྱི་འགྱུར»: the same title, the same maker (the teacher Candragomin's pupil, «ཟླ་བའི་བཤེས་གཉེན», which the Derge and Phur lcog catalogues render Candramitra) and the same two translators. Beside it, the Tengyur has no other Dream Tārā practice in the catalogues read (svo:i472-473, svo:i736 list one). So the catalogue entry names the work whose text is quoted. Limits: the Derge text is an etext, the Narthang line a machine reading, and the Narthang manuscript's own text of the practice was not compared with the Derge one.
