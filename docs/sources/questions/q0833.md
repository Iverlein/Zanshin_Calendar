# Is the Svapnohana's fourth-watch line «ཐུན་བཞི་ཟླ་བ་ཕྱེད་བར་དུ» absent in the Narthang prints and the Co ne print too, or only in Peking?

If a Peking omission, the half-month span stands only on the Derge text.

## Answered 2026-11-10

Answered by RD280: the Narthang manuscript (I2KG212312 img. 284) carries «ཐུན་བཞི་ཟླ་བ་ཕྱེད་བར་དུ» (moderate); the line is absent in the Peking print alone, so the half-month span stands on the Derge etext and the Narthang together. The Co ne is by machine reading only (q873).
