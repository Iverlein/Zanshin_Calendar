# KP box 12: is «སའི་འཕུང་བྱེད» the same lord as WB's «ས་ཕུང་ནག་པོ», and «ཉི་ནུབ» the same as WB's «ཉི་ནག»?

WB work 12 has «ས་ཕུང་ནག་པོ་རྒྱུ» and «ཉི་ནག». Related: the box 60 question on «ཉི་ནུབ».

## Narrowed 2026-11-21 (inv-k)

A Bhutanese table manuscript (BDRC MW26041, I1KG11905 etext p. 375) prints box 12's run as «… པི་ལིང་ སའི་འཕུང་བྱེད་ཉིནག་ འགྲོ་མིའི་བདུད་གཅོད་སོགས།»: the same sequence as KP (kp:i27) and as WB's «པི་ལིང་ས་ཕུང་ནག་པོ་རྒྱུ། ཉི་ནག་བདུད་གཅོད་ལ་སོགས་ངན།» (pi ling, the earth-heap lord, the great black day, the demon-cutting); the same book names the lord's course times «འཕུང་བྱེད་ནག་མོ་རྒྱུ་དུས» (p. 395). So «སའི་འཕུང་བྱེད» stands in WB's «ས་ཕུང་ནག་པོ» place, and the manuscript reads «ཉི་ནག» where KP's scan is read «ཉི་ནུབ». That the two are one lord each is likely from the position and the shared tail, but no text says it, and KP's own syllable («ནུབ» or a worn «ནག») is not settled by the manuscript's OCR.
