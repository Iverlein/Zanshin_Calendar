# What «བཞི་བརྒྱ་དོན་བཞི» counts among the earth lords' comings

On p. 175, what does «བཞི་བརྒྱ་དོན་བཞི» in «ལོ་ཟླ་ཞག་དུས་ལྷའི་བྱོན་གྲངས། བཞི་བརྒྱ་དོན་བཞི་ཡོད་པ་ལས།» count (404 comings, or "four hundred, four of them the meaning"), and how do the seventy-two that dwell, the 21 that never move and the nine of the underworld (p. 177) add to the 102 the year-month-earth-lords file names?

## Answered 2026-10-28

«བཞི་བརྒྱ་དོན་བཞི» is 474, not 404: «དོན» is a number word, as in «གནས་པ་དོན་གཉིས» (72) on p. 174. The notes (vol. 2, pp. 534–535) build the sum 231 + 124 + 81 + 37 + 1 (Rāhu) = 474; the 102 that never move (72 + 21 + the nine of the nine levels under the earth) are counted apart. See claims/wb-earth-lords-474-sum.md (RD63).
