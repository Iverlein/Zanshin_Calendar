BDRC's exact-phrase search for the two lines («བཅུ་གཅིག་པའི་སར་ཉི་མ་ཡོད་ན», «སྤེན་པ་ཡོད་ན་ནོར་སྣ་ཚོགས་ཐོབ», «སྤེན་པ་ཡི་ནི་ཀེ་ཏུ་ལ», «མཁྲིས་ནད་ཚད་ནད་གྲང་ནད་འོང») gives two hits each, both in the same two books: Bod kyi rtsis rig kun 'dus chen mo (VEIE0OPI2F246A26_I4717) and the Bzo rtsis zlos gar, vol. 2 (VEIE0OPI51EA6051_I2PD16001), which prints the same Mchog dga' text.
