# The 1st month head's weekday numerals in the model almanac

In the 1st month's head of the model almanac the weekday line (dar, gud, skyod, zhud with the weekday numerals under arcs) shows three numerals after «dar» that read 3, 0, 1 and then 6 and 5 after the next words, which does not give the seven weekdays once each as the 11th, 12th, 2nd and 4th heads do. Which numerals does the line mean, and does the print have a misprint here? (RD200, corpus/wb/ch13.md)

## Answered 2026-11-08

The 1st month head's weekday line reads dar 3, 0, 1; gud 2, 4; skyod 6; zhud 5: each of 0–6 once, no misprint (RD200, second pass 2026-11-08, Gser thang reprint img. 164).
