# Which side is the hearth god's in each cell of the upper table of WB vol. 1 p. 133

In the upper table the hearth god's side («ཐབ་ལྷ་…») is read by the machine readers as east, south, west or «ཐབ་འོག» with disagreements («ཐབ་ལྷ་སྲུང» for the rat); which side is it in each cell? (RD78)

RD182 (2026-11-06), narrowed: scan (img. 140, 3.5–10×): the monkey's cell reads «ཐབ་ལྷ་ཤར» (east); the dragon's cell is «ཐབ་ལྷ་ནུབ» (west) (the first pass's «ཐབ་འོག» was wrong); the garbled etext gives east for the hare and horse, west for the bird and sheep, «ཐབ་འོག» for the pig or dog; ten of twelve cells are not distinguishable on the 12-pixel print.
