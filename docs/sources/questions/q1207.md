# KD vol. 1 p. 493: the Dpal ldan effect reckoning's skipped date «༢ ༡ཆད»: the 21st, or the 2nd and the 1st?

In the Lhasa almanac of a wood pig year, the 3rd month head, the Dpal ldan effect reckoning's skipped date is printed «༢ ༡ཆད» with a space (KD vol. 1 p. 493, etext p. 509). Only the lent scan (bdrc-W28845, leaf = printed page + 16) can show whether it is one number, 21, or two, the 2nd and the 1st.
