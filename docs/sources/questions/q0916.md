# Does the 星槎ラボ 延宝2 大ざつしよ, the earliest print, or any other 万代大雑書 print set out the table 夢を見て語らざる日 with a legend for the slash?

RD308; the NDL has some seventy-six 大雑書 titles, almost all restricted to the library's reading rooms.

Narrowed (inv-r, 2026-11-13): the table that mdz:p11 quotes is Ito Takayuki's transcription of the 万代大雑書古今大成, and its 凡例 says «割注中の改行箇所は／で示した» (a line break inside a two-line small note is shown by a slash): the slash is the editor's sign, not the print's, and the print has no legend for it; its only legend is the closing line 右の日の夢ハ善悪ともに語らず. Claim ozassho-slash-is-the-transcribers-line-break. The 延宝2 大ざつしよ (a web search for the 星槎ラボ copy found nothing) and the other prints are not seen; whether the two lines of a cell are two groups with a meaning stays open.

Narrowed (inv-qq, 2026-11-14): the table has an older source, the 拾芥抄's 不語夢日 (mdz:i772010, claim shugaisho-fugomu-nichi-is-source-of-not-told-days): the same two-column cells, no legend for the columns, the reason given in the entry. The NDL Lab full-text search finds no 万代大雑書 print with the table (searches 夢を見て語らざる日, 夢を見て語らず, 夢語らず, 夢を人に語らず: no hit); the 延宝2 大ざつしよ is not in the NDL's open text, so the earliest print is still unseen.
