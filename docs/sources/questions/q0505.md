# Which root tantra is the «མཱུ་ལ་ཏནྟྲ» of p. 450

On p. 450 (img. 456), line 3, the verse quotes «མཱུ་ལ་ཏནྟྲ་ཡས» (the Mūlatantra, the root tantra, read on both prints) for the rule that one who has not put on his own armour is struck by his own deed: which root tantra is meant? (RD84)

**Searched 2026-11-16 (inv-z2).** «མཱུ་ལ་ཏནྟྲ་ཡས» 0 hits (WB's own spelling is not found in another text), «མུ་ལ་ཏནྟྲ་ལས་» 1 (the Drukpa Mirror, the trigram verse; see q658). The root tantra is not named by any text reached.

No other text quotes it or names its Mūlatantra. See also q658. Open.

**Narrowed 2026-11-24 (sweep from q546, q658).** Answered as to the name by q546 (2026-11-06): «མཱུ་ལ་ཏནྟྲ» is the Sanskrit word mūlatantra, root tantra, spelled in Tibetan letters, not a title; no text reached names the root text, and the armour verse is found in WB's copies only (q658). So the question is narrowed to which root text, which q658 carries.
