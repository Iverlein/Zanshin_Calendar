# What does «མ་རྒྱབ་གྲོགས་མདུན་གཏད་པ་གཅེས» ask for on p. 313

In WB vol. 2 p. 313, line 1, what does «མ་རྒྱབ་གྲོགས་མདུན་གཏད་པ་གཅེས» ask for: which direction is the friend put in front? (RD79)

## Answered 2026-11-05

As far as the page goes (RD112, RD159): it says only "the friend in front" and names no direction.
