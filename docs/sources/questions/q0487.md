# The 歳刑 in a whole quarter or in one branch

The 暦林問答集 places the 歳刑 in a whole quarter by the triad (§10); the modern table in one branch of it. Does an old text give the single branch for the 子, 寅, 卯, 巳, 午, 申, 酉, 亥 years (RM's earth line gives it for 丑, 辰, 未, 戌 only, and as an explanation), and does the printed 方位吉凶図 shade the quarter or the branch?
