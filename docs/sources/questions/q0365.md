# For whom the four reckonings of «བརྗེ» are

For whom are the four reckonings of «བརྗེ» counted from the five rats (WB vol. 2, p. 23, l. 22): monks (བཙུན, btsun, or a form of «བྲེ»), as their vajra, discipline and begging suggest?

**In part 2026-10-25 (RD51, [claims/ch27-brje-set-is-the-monk.md](../claims/ch27-brje-set-is-the-monk.md)).** «བརྗེའི» is read as printed; by content (vajra, discipline, begging) and its place between the king's set and the mantrin's set it is the monk's set, matching «སྔགས་བཙུན» in the close. That «བརྗེ» spells བཙུན is not shown.

**Narrowed 2026-11-16 (inv-g, the question file brought up to the claims).** Two claims written after RD51 bear on this and the question did not list them: [ch27-brje-set-zg-spiritual-friend](../claims/ch27-brje-set-zg-spiritual-friend.md) (Zhechen Gyaltsab, same sets in the same order, names the second circle-set's person the spiritual friend (dge ba'i bshes), with the same golden vajra, crystal rosary and maṇḍala; the dictionaries give «བརྗེ» only as "exchange") and [ch27-brje-or-bande-etext](../claims/ch27-brje-or-bande-etext.md) (the 1996 etext reads the stack both «བརྗེ» and «བནྡེ», "monk", which the scans do not exclude). So by content and by the one parallel witness the set is for the teacher, spiritual friend or monk; which word the stack spells is not shown.
