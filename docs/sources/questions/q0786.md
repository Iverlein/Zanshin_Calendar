# Does EB9's 大雑書 or 夢占吉凶秘伝書 name a date, a day of the cycle or a season for a dream beyond the 万代大雑書?

Needs the book itself (a library copy); it is in no online form.

Narrowed (inv-qq, 2026-11-14): the NDL Lab full-text search (lab.ndl.go.jp/dl/api/book/search) for 不語夢日 finds the older table in the 拾芥抄 (mdz:i772010): it names the rule by month and day branch of the cycle, with no season and no calendar date, and no night for a first dream. The same search for 夢を見て語らざる日 finds no Edo print (the OCR does not carry it), and for 夢を語らざる日 only the 日用新旧暦の栞 (1914, pid 948076, a listed line 辛未◎夢を語らざる日, a calendar day of the cycle; the page was not found on the image, the OCR page number does not match the image number). EB9 itself and the 夢占吉凶秘伝書 are in no open form; still open.
