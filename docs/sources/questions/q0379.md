# «ལྷ་ཁང་འགོའི» or «ལྷ་གང», «བསྔོས་ཚང» or «བསྡུས་ཚད»

In point 12 the scan prints «ལྷ་ཁང་འགོའི» (a temple's start) where KD's print has «ལྷ་གང་འགོའི» (which god) and WB «ལྷ་གང་ཕན»; in point 11 «བྱིས་པ་བསྔོས་ཚང» where KD has «བསྡུས་ཚད»: which are the readings, and what is a child's «བསྔོས་ཚང»?

RD166 (2026-11-06): point 12: WB's nineteenth point (p. 465) has «ཕན་པའི་ལྷ་གང་ཡིན», so «ལྷ་གང». Point 11 matches WB's eighteenth point (the child's srid); the word itself is a dead end. The scan's «ལྷ་ཁང» was not re-read.

**Narrowed 2026-11-14 (inv-ddd).** Point 11: the Yul mdo khams stod collection (MW1PD152297) and Tshul khrims rgyal mtshan's collected works (MW1KG10375, in the *Moonbeams*) read the line «བཅུ་གཅིག་རྟ་བྱིས་པ་བསྡོས་བླ་ཤིང་སྲིད་ཚད་རྩིས། བྱེད་ན་ལྗོན་ཤིང་ཆུ་མིག་དང་།» (BDRC snippets, search-only etexts; Wylie *bcu gcig rta byis pa bsdos bla shing srid tshad rtsis*), the Zlos gar «བྱིས་པ་བསྡོས་ཚད་རྩིས» (*byis pa bsdos tshad rtsis*), KD «བསྡུས་ཚད»: so the line ends in «ཚད» (tshad), not «ཚང», and the heading carries the la tree and «སྲིད་ཚད» (srid tshad, the measure of existence) as WB's eighteenth point «བླ་ཤིང་… བྱིས་པའི་སྲིད» has them; the scan's «བསྔོས་ཚང» is a variant of «བསྡོས་ཚད» in this family. «བསྡོས» itself is not glossed: the dictionaries have only «bsdos» as the past of «sdo» (to attack, challenge) and the Dung dkar «meet, encounter»; «བསྡོས་ཚད» as a phrase 0 hits there. Point 12 stands as RD166 (the same Yul mdo khams stod and KD prints read «ལྷ་གང་འགོའི»; BDRC «ལྷ་གང་འགོའི» 5 hits, «ལྷ་ཁང་འགོའི» 0).
