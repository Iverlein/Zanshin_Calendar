# Which syllable has dropped from the black pebble's power verse «ནག་ནང་བརྗེ་གྲོང་སྤྲང་བྱེད» on p. 23, and does «བརྗེ» name a kind of religious person

The «བརྗེ» set's power verse for a black pebble, «ནག་ནང་བརྗེ་གྲོང་སྤྲང་བྱེད» (WB vol. 2, p. 23, l. 25), has six syllables where the verses round it have seven, on the 1996 print and on its Gser thang reprint alike: which syllable has dropped, and does the verse, read with «བརྗེ» as the one who goes begging, name the set's person, so that «བརྗེ» is a word for a kind of religious person? (RD89)

RD178 (2026-11-07): Narrowed: on the Zhol print (img. 659, line 1, 8×) the verse has the same six syllables and «བརྗེ» (a ba and a stack with the tail of ཇ); no seventh syllable on any print, so the missing syllable is not a printer's accident of one setting.
