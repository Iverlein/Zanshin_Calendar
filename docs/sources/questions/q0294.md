# «རྗེ་ངན་རྗེ་ཆུང» or «ཇེ»

«རྗེ་ངན་རྗེ་ཆུང» (p. 104, the eighth place): «རྗེ», the lord, as the reprint reads, or «ཇེ», "ever worse, ever smaller", as Yigdzin-1 reads the second on the 1996 print?

## Answered 2026-10-23

Answered 2026-10-23 (RD46, with fair confidence): the blocks read «ཇེ་ངན་ཇེ་ཆུང», ever worse, ever smaller.
