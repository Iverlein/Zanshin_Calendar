# *Rta chung* of the sounding: gre or not

Is *rta chung* of the sounding (WB vol. 2, p. 92) gre, when the Bhutan collection's verse of bad mansions lists the two side by side?

## Answered 2026-11-06

RD180 second pass (2026-11-06), machine-read digits: in the 1996 etext's numbered mansion lists «རྟ་ཆུང» carries the number 10, the same as «གྲེ/གྱེར» (img. 404 «མཆུ(༩) གྱེར(༡༠)» with «རྟ་ཆུང(༡༠)» a line before; img. 389, 393, 412, 414 agree). So rta chung is a second name of the tenth mansion, gre.
