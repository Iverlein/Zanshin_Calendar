# Why the 暦林問答集 §11 adds horses and cattle to the 歳破

Why does the 暦林問答集 §11 add horses and cattle to the 歳破, when no Chinese source quoted in the 協紀辨方書 has them there? Is there a source for the clause in the 暦例 it cites?

RD172 (2026-11-06): dead end.


Narrowed (inv-sss, 2026-11-14): the clause is introduced by «暦例云» and the words before it («歲破土曜之精 … 故云破») are quoted unchanged in the 大日本国語辞典 and 方位細鑑 (pid 2541333, which gives the same text in Japanese and has no livestock clause), but the NDL full text for 馬牛之類不可 finds only the 暦林問答集 (in the 群書類従 and 古事類苑 printings); 歳破 + 馬牛, 牛馬, 六畜 (as one word) 0 hits; a web search for the 暦例 phrase gave only modern folk-astrology pages. The 暦例 cited is not found as a text; the clause stays without a source. The livestock rule in the Chinese rows belongs to the 歳煞 and 豹尾, so a transposition in the 暦林問答集's source is possible but not shown.
