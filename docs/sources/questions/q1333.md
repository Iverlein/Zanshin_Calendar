# Which chapter of the Susiddhikara, and which Toh number and Derge folio, holds the offerings verse that Mipham's text quotes

From inv-b (2026-11-21) on q1297: the verse is in the Kangyur's Legs par grub par byed pa'i rgyud chen po las sgrub pa'i thabs rim par phye ba (etext VE23703_1362); chapter and Toh number not checked.

## Searched again 2026-11-21 (inv-p)

The etext VE23703_1362 named in the note above is not the Kangyur's Susiddhikara but a Tengyur volume of Yamāri commentaries (Dpe bsdur ma I1PD95868 is the same text): the verse «ཚེས་བརྒྱད་དང་ནི་བཅུ་བཞི་དང་། །བཅོ་ལྔ་དག་ལ་སྒྲུབ་པ་པོས། …» stands there inside the Yamāri pañjikā «Rin chen phreng ba» (Kṛṣṇayamāri, MW23703_1919, volume page 334 of the first print), quoted among lines of a longer run on recitation and vows, the work not named at that place. BDRC exact phrase search for the first two lines (1 hit) and the third and fourth (2 hits) finds only these two copies of that commentary, no Kangyur volume. So the chapter, the Toh number and the Derge folio of the Susiddhikara are still unread, and the claim's wording «the Kangyur etext» should be read as «a Tengyur commentary that quotes it»; the attribution itself rests on Ngor chen's and Tsong kha pa's «ལེགས་གྲུབ་ཏུ» introductions. Next step: the Kangyur Susiddhikara (Toh 807) read directly in a Kangyur etext, searching a different line of the verse run («གསང་སྔགས་ལུང་རྣམས་ཀུན། །ཡང་དག་རྒྱས་པར་ཤེས་པར་བྱ»).
