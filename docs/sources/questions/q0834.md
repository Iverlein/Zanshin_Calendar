# What is the Sanskrit title of the Svapnohana on the Peking print (img. 315 line 1)?

Five signs show, the first «སྭ», the third «ཨུ»; the stack after them is not told apart.

## Answered 2026-11-14

Answered 2026-11-14 from BDRC's work records and Monier-Williams: the Peking title line is Svapnohana (svapna + ūhana, «examination of dreams»), in Tibetan letters «སྭཔྣ་ཨུ་ཧཱ་ན». BDRC's Peking record MW1KG13126_2621 holds it as an incipit title, «swap+na u hA nA» (pa, པྣ), as the Narthang etext record MW2KG5015_1416 does («s+wap+nA u hA nA»); only the Derge record has ba («s+wab+nA»). Only the pa stack spells svapna. The second stack of the print itself was not read at higher size than the 3200 px the server gives (q1088, q1190). claims/svapnohana-sanskrit-title-incipits-bdrc-three-prints.md.
