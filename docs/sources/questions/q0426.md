# Which six fight in the notes' 360 starting points?

In the notes' close on the 360 starting points (vol. 2, p. 538, img. 546, l. 2–4) the six that fight are written as «སྲོག་ལུས་དབང་ཀླུང་དབང་བླ་རང་དུར་གཤེད་དུར»: eight words; which six are meant, and is the second «དབང» a slip, the luck among them though the worked example does not use it?
