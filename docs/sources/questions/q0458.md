# Which line is missing for Sesame-pounding among the eleven karaṇas of pp. 349–350

P. 349–350's eleven karaṇas: the machine has no line for Sesame-pounding (ཏིལ་བརྡུང་) between Virtue and House-born, and p. 350's trial by a vessel of water ("the earlier half's shadow") is read only as far as the machine gave it; read pp. 349–350 line by line on the scan.
