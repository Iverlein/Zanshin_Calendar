# KP box 22: does the print have «ཁྱིམ» after «ཐེ་སེ» (RD5 read «ཐེ་སེ་ཁྱིམ»), the queen Tekhyim?

Not seen at 4.2×.

## Answered 2026-11-21

Answered: no «ཁྱིམ» belongs after «ཐེ་སེ» in box 22. KP's last two lines (kp:i36b) are nyi nag, the se; Grum bu, the earth king, the dragon god, the earth's destroyer; WB's work 23, which box 22 digests, has «ཉི་ནག་འབྲུག་ལྷ་ཐེ་སེ་དང་། །ས་རྒྱལ་གྲུམ་བུ་སའི་ཕུང་བྱེད། །ནག་མོ་རྒྱུ་དུས་སོགས་ལ་འཛེམ།» (white-beryl-ch34.md): the same six names, «ཐེ་སེ་» followed by «དང»; no Tekhyim. Thé-khyim (ཐེ་ཁྱིམ) is a different lord in WB's year-lords list (wb.2:p96-97, no. 2, the queen) that this verse does not name, so a «ཐེ་སེ་ཁྱིམ» would be a seventh name KP has beyond WB; with the 4.2x look that found no such syllable, RD5's «ཁྱིམ» is not in the print. State: WB verse by etext/scan reading, KP scan at 4.2x.
