# Who is the lama of the Śramaṇā rite in the be'u bum's dream set, is he in the Paṇ chen Śākyaśrī's line, and does Tāranātha's section come from the same source

The set says «the lama says, and it is established by experience» ([p339]); the Lcang lung list takes the Śramaṇā mantra from the Paṇ chen Śākyaśrī; Tāranātha's section has the same rite in the same order.
