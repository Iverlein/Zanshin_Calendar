# WB ch. 19 p. 213: do the wheel (འཁོར་ལོ) and the star (སྐར་མ) each count 27 in the first circle's long figure?

The figure reads 82,776,132,766,945,179,600 on the reprint and fits the word-numerals ཀླུ, འཁོར་ལོ, ཐུབ་པ, རོ, འདོད, སྐར་མ, མཚམས, དུས, བུག, མཚོ, དབང, གཟུགས, རི, བུག, རོ only if both count 27.
