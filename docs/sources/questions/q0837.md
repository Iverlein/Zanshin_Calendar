# Which is the third syllable of «ཛ་ཏ་པ/ཀ་ཡི་ཕྲེང་བ» (the jātaka garland)?

Peking looks like པ, the Derge etext has ཀ.

## Answered 2026-11-10

Answered by RD298: the jātaka garland's third sign is པ on the Narthang manuscript (not the ཀ the same hand writes in «ཀུ་ཤའི»), so Narthang and Peking read «ཛ་ཏ་པ» against the Derge etext's «ཛཱ་ཏ་ཀ» (moderate); the Dpe bsdur ma note agrees.
