# The eight places that open death for khen, gin and zon

The eight places that open death (p. 90) name only *li*, *khon*, *dwa*, *kham*, *zin*; the notes (p. 510) add *khen*, *gin*, *zon* "by implication": which animals die on those three?

**Narrowed 2026-11-03 (sweep from RD140).** The five lines of p. 90 place all twelve animals (2+2+2+4+2), so khen, gin and zon can only take animals again: each has the element of one of the five (khen iron like dwa, gin earth like khon, zon wood like zin), which gives the pairs khen horse and snake, gin tiger and hare, zon bird and monkey. Still an inference; no text read names the animals (reckonings.md, *The eight places that open death*; Mipham's note is on p. 509).
