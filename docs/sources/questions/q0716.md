# ཚོམ་རྐུན (entry 51) and ཆོམ་རྐུན: one word?

ཚོམ་རྐུན (entry 51) against ཆོམ་རྐུན (p. 211): is it one word, "robbers", spelt two ways? (RD194, corpus/wb/ch18.md)

## Looked at 2026-11-13 (inv-x)

BDRC full-text search: «ཆོམ་རྐུན་རྒོད» 14 hits, «ཚོམ་རྐུན་རྒོད» 0; «ཆོམ་རྐུན་རྒོད་ལ་དབྱར» 4 hits (the Gser thang etext MW3CN5026, MW1KG12714 the Dehradun print, MW25151, MW2PD17386_D19206), «ཚོམ་རྐུན་རྒོད་ལ་དབྱར» 0. The Gser thang etext writes ཆོམ་རྐུན (entry 51 too: «ཤར་དུ་མུག་འབྱུང་ཆོམ་རྐུན་རྒོད»). Every print found has ཆོམ་རྐུན (*chom rkun*, robbers), so ཚོམ་རྐུན is a misreading or a slip of the scan of entries 51 and 50; one word. Etext evidence; the stack on the scan not seen. The question stays open for the scan.

## Answered 2026-11-14

One word, "robbers, thieves". ཆོམ་རྐུན (chom rkun) is in the dictionaries (Rangjung Yeshe "robbers, thieves", Ives Waldo "robber, bandit, thieves", the Mahavyutpatti's caura, Tshig mdzod chen mo's example «chom rkun gyi nyen dogs»); no dictionary has a headword «tshom rkun». The spelling ཚོམ་རྐུན (tshom rkun) is nevertheless in print for the same word: BDRC's full-text search for «tshom rkun» finds it in ritual texts («dgra jag tshom rkun», enemies, bandits, robbers), where it stands beside jag pa, the bandits. So the p. 212 entry 51 is read as the same word whichever spelling the stack is; the earlier finding stands that the etexts of WB itself have ཆོམ་རྐུན in both places, and the stack on the scan is a separate question (q1201).
