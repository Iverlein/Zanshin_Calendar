# KP box 57: is the lone «ཉི» after «དབུལ» short for «ཉི་ནག», or WB's «དབུལ་པོ་ལག»?

Box 57 has «དབུལ་ཉི་» where WB has «དབུལ་པོ་ལག་».

## Searched again 2026-11-21 (inv-k)

A Bhutanese table manuscript (BDRC MW26041, I1KG11905 etext p. 409) prints «དབུལ་ཉི་ ཕུང་» in the slot of KP's box 57, and a verse of the same book (pp. 226-227) has «དབུལ་ཉི་བར་ཁྱི་གནམ་ཁྱི་སྦྱོར» followed, a line later, by a separate «ཉིནག་ཆེ་ཆུང»: so «དབུལ་ཉི» is the table tradition's own unit and not KP's cutter shortening «ཉི་ནག» (claim bhutan-table-book-parallels-kp-boxes). WB's councils verse has «པི་ལིང་ཕུང་ཟོར་དབུལ་པོ་ལག» (ch. 34). Whether «དབུལ་ཉི» is a name of its own or a corruption of «དབུལ་ལག» is not stated by any text found; BDRC phrase search «དབུལ་པོ་ལག» (21 hits, all WB's prints and handbooks) gives no gloss. Open.
