# The first circle's broken luck remedy, p. 4

The first circle's luck remedy, «[…]ང་གསོ་འཛུགས» (p. 4, l. 7): the first syllable is broken on both the 1996 scan and the reprint; does another print (WBZ, the Taikhang) read it?

## Answered 2026-10-23

Answered 2026-10-23 (RD46): the Zhol blocks read the broken syllable «ཀླུང», «ཀླུང་གསོ་འཛུགས», the river (or wind-horse) restored.
