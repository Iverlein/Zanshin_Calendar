# Is 端午's festival plant 菖蒲 the sweet flag or the garden iris, and which should the painting show?

Both pages read name only the word shobu; the T6.3 table has the iris.

## Answered 2026-11-24

RD409 follow-up. The sweet flag. Japanese Wikipedia's ショウブ: a waterside plant with sword-shaped leaves and a small yellow-green spike, used for the 端午 bath and hung from the eaves, "a quite different plant" from the garden iris (ハナショウブ) that its name is confused with. The frame shows the sword-shaped sweet-flag leaves, not an iris flower. See [festivals.md](../festivals.md), follow-up of 2026-11-24, and [claims/tango-shobu-is-the-sweet-flag.md](../claims/tango-shobu-is-the-sweet-flag.md).
