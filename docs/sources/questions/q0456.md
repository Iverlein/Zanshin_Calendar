# Which digits do pp. 335–336's day-combinations and pp. 341–342's tables carry

Pp. 335–336's combinations (the Accomplishing, Paired, Mara-and-Victor, Accomplished, Auspicious, Increasing, Rough, Agreeing days, the seven Mara days, the Disagreeable and Unfit days) name planets and mansions by number, read only by the machine; the tables of pp. 341–342 give the same combinations by weekday. Both need the digits read on the scan, cell by cell, and the verse set against the table.
