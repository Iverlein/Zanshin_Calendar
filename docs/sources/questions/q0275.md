# «སེར་གསུམ» in the rebirth by the mewa

In the rebirth by the mewa (WB vol. 2, p. 70, ll. 14–15), «སྨེ་བ་དཀར་གསུམ་ལྷ་རུ་སྐྱེ། །ནག་གཉིས་ལྗང་གསུམ་ངན་སོང་སྐྱེ། །དམར་གཉིས་སེར་གསུམ་བར་དོར་འཁྱམ། །ལྔ་སེར་ལ་ཤི་མི་ལུས་ཐོབ།», which mewa does «སེར་གསུམ» name, since five yellow is given a human birth in the next line? The notes (p. 501) repeat «དམར་གཉིས་སེར་གསུམ» without explaining it.
