# Ch. 3 p. 24: figures (༩༣), (༥༤), (༧༩༠), (༦༩༠), (༦༠༧) against the chain

p. 24 prints (༩༣), (༥༤), (༧༩༠), (༦༩༠), (༦༠༧) where the chain and the glosses give 936, 57, 720, 670, 647. Does the Beijing 1996 print (I1KG12906) read the same, which would make them WB's own printed slips? RD197c (2026-11-08).

## Answered 2026-11-12

RD213x, 2026-11-12: the 1996 print (I1KG12906 img. 34) has the same shapes as the reprint in all five figures, among them a two-digit 936; the print's own slips, shared by both (passage wb.1:p23-27). The 1996 scan is too small to improve on the reprint's reading of single glyphs.
