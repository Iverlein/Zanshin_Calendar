# The daughter's secret obstacle named last with no symptoms

P. 390, «མ་སྤར་ལི» for the son and «མ་སྤར་ཁམ» for the daughter (Zhol img. 512, l. 4): the line's close «ཚོར་བ་དཀའ», 'hard to feel', is the daughter's secret obstacle's own; is that why the daughter's is named last and with no symptoms? See year-of-life.md, RD126.

RD174 (2026-11-06), narrowed: the Moonbeams' version (KD vol. 3 markers 674–675, etext) lacks «ཚོར་བ་དཀའ»; an interlinear bracket note reads «མ་སྤར་ལི» as son's and «མ་སྤར་ཁམ» as daughter's secret obstacle, as Mipham does. LT, UT and the notes also lack the clause, so it is WB's own. No source gives a reason for the order.
