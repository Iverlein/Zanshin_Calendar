# Which numerals and direction of counting does the outer door table of ch. 32 p. 287 carry

On WB vol. 2 p. 287 the outer door table gives places 1–8 per side as bad, middling or good (east bad 1, 2, 3, 7, 8; south bad 1, 3, 4, 6, 8; west bad 7, 8; north bad 1, 2, 3, 8; corner doors all bad), read by the machine only: which numerals does the scan print, and from which end are the places counted? (RD81)

**Narrowed 2026-11-16 (inv-m).** The numerals: the scan prints ordinal words, no digits (RD114, `ch32-outer-door-places`). A third copy of the table's words: BDRC phrase search «ཤར་གྱི་དང་གཉིས་གསུམ་པ་དང་» 3 hits, WB's 1996 etext, the Gser thang etext and *Bzo rtsis zlos gar* (MW1PD95727, a craft-reckoning work in the Gangs ljongs rig bcu collection, search-only, snippet only): «ཁང་པའི་ཕྱི་སྒོ་སྤྱིར་བཏང་དུ། །ཤར་དང་ལྷོ་བཟང་དེ་ཡང་ནི། །ཞིབ་པར་ཕྱོགས་རེར་བརྒྱད་རེ་ཕྱེ། །ཤར་གྱི་དང་གཉིས་གསུམ་པ་དང་། །བདུན་བརྒྱད་ངན་ལ་བཞི་ལྔ་དྲུག །བཟང་ཞིང་…», the same wording, so the east's «དང་» is the first place (bad) on three copies; none says from which end the eight are counted. «བདུན་བརྒྱད་ངན་ལ་བཞི་ལྔ་དྲུག» 4 hits (the three and the Zhol print), «ཕྱི་སྒོ་ཕྱོགས་རེར་བརྒྱད་རེ», «སྒོ་དང་པོ་གསུམ་པ་བཟང་» 0. Direction of counting: open.
