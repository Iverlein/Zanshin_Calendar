# Which animal does the «དུར» of «དུར་གྱི་སྟེང» name for each of the four first months of the seasons

In WB vol. 2, p. 219, which animal does the «དུར» of «དུར་གྱི་སྟེང» name for each of the tiger, snake, monkey and pig months? The triads give the dog, ox, dragon and sheep, but ch. 31 does not say which count it uses (RD69).
