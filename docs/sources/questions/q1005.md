# The Shechen etext opens four Lama Gongdü texts of vol. 42 (the dream text and three others) with a run of 6 to 8 placeholder marks before «namo guru deva ḍākinī hūṃ»; is the ornamental string before the homage one fixed opening of the cycle's texts, written with as many glyphs as the text needs, and what is it?

RD355.

## Answered 2026-11-14

No. The run is not one fixed opening of the Lama Gongdü cycle's texts, and nothing read says what the string is. In the Shechen etext of vol. 42 the placeholder mark (U+0F88, the etext's stand-in for a form it did not read) stands before the homage «namo guru deva ḍākinī hūṃ» in seven texts, five to eight marks each (five, eight, eight, five, eight, five and six), and in none of the four texts of the same cycle in the Shechen vol. 7, which open with the same title formula and have no mark or string between title and homage (claim dds-lama-gongdu-placeholder-run-is-in-seven-texts-of-vol-42-and-in-none-of-vol-7, RD403). The count follows the typist's glyph count on each page, so it varies with the text. The string is on the print's page (lgd.42:p962b) in an ornamental letter, copied by hand as well as printed, and was never read by eye or by machine; whether it is the same string in each of the seven texts was not compared on the scans. What it is, a seed-syllable string, a mantra in ornamental script or an invocation, no source says (BDRC phrase searches found no etext that writes it in plain letters). State: etext for the count, scan for the one page.
