## Narrowed 2026-11-24 (inv-g), the second place settled

- ch. 10 line 82, «ནག་པོ་དབང་ཉིད ༡༢༥»: 125 is right. The word is «ཉི» (sun, 12) with the metre's final ད, so the run «དབང་ཉི» (dbang 5, nyi 12) spells 125 by the tool (`numwords.py spell «དབང་ཉི»` gives 125, units first: 5, then 12), and the same pair stands in ch. 9 (corpus/wb/ch09.md line 120, «དབང་ཉིད ༡༢༥» before «མེ་འདོད ༡༣༣» and «མཚོ་འདོད ༡༣༤»). The earlier note treated «ཉིད» as a numeral 25 and so found no match; there is none such, and nothing is left to correct.
- ch. 7 p. 49, «victor, fire-pair three» 4898: unbacked, as asked. The stored line (corpus/wb/ch07.md line 238) has «རྒྱལ་བ་མེ་ཟུང་གསུམ [?]» with no bracketed figure; the words spell 2324 (victor 24, fire 3, pair 2, read from the last) and, if «གསུམ» is a plain 3 after them, 32324 (the tool does not know «གསུམ»). The line for the white one a little on (line 238, «རྒྱལ་བ [?] མིག་ཟུང [?] གཉིས་གཉིས») has the same shape, the stacked unbracketed figures of the q778 kind, so the print's value is not read on this page either. The English figure 4898 has no source in the passage and should be taken out when the passage is next touched.
