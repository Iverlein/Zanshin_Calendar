# KD vol. 3 pp. 731-732: what are the «dag pa'i gza'» (pure planets) of the Kalacakra sets?

The digest names the seven accomplishing meetings, seven death meetings and fourteen burning dates (sreg tshes) of the pure planets without listing them. Check whether burning-dates.md already holds a source for them.
