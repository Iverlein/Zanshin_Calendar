# On the Kazi print (I6132 img. 559) and the Zhe chen and Ngodrup hands, is the letter after «མ» in the mixed kind's last clause ཕ or བ, that is «མ་ཕྱེད་ན» or «མ་བྱེད་ན»?

RD318; only Yigdzin-1 read it, and it reads ཕ.

**2026-11-24 (inv-o).** Kazi I6132 img. 559 (2324x430, folio 549), whole page read by Yigdzin-1 and MITRA (`schedule.py slot`): both give «སྤེལ་ཞིང་མ་ཕྱེད་ན་ཆོ་འཕྲུལ་དུ་ཤེས་པར་བྱའོ» (ཕ), so MITRA now agrees with Yigdzin-1. At 3x on the line crop the letter is not legible by eye (print too small at this scan size), so the ཕ stays a two-model machine reading, not a read letter; the Zhe chen and Ngodrup hands were not looked at.
