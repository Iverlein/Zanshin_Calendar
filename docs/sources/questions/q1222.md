# KP box 60: what is «ཉི་ནུབ» (the sun's setting) before Rahu, which WB's councils lacks?

Compare box 12's «ཉི་ནབ».

## Searched again 2026-11-21 (inv-k)

The Bhutanese table manuscript (BDRC MW26041) has box 60's run («རཱ་ཧུ དྲ་ཆེན་ པ་ལིང་ཧལ་ཁྱི … ཀི་ཀང་ དབུལ་ ལོ་ཟླ་ཞག་ནག་ཕུང་ཟེར…», I1KG11905 etext p. 410) with a garbled pair of syllables where KP's scan is read «ཉི་ནུབ» before Rahu; the same book's box-12 run reads «ཉིནག» in the slot where KP's box 12 is read «ཉི་ནུབ» (p. 375). WB's councils verse names «ལོ་ཟླ་ཉི་མ་ནག་པོ» and «རཱ་ཧུ་ནག་པོ» (the black day; black Rahu). The parallel makes «ཉི་ནག» likelier than a «setting of the sun» in these runs, but the book is OCR and KP's own reading stays «ནུབ» on the scan; BDRC phrase searches «ཉི་ནུབ་རཱ་ཧུ» and «ཉི་ནུབ་རཱ་ཧུ་དྲ་ཆེན» 0 hits.
