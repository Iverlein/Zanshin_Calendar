# Which root tantra gives «རང་གིས་གོ་ཆ་མ་བརྩམས་ན། །རང་གིས་བྱས་པ་རང་ལ་བརྡེག»

Which root tantra gives «རང་གིས་གོ་ཆ་མ་བརྩམས་ན། །རང་གིས་བྱས་པ་རང་ལ་བརྡེག» (WB p. 450)? Both etexts garble the name («མུ་ལ་ཏནྟཱ», «མུལ་ཏཅུ»).

## Answered 2026-11-06

RD168 (2026-11-06): «མུ་ལ་ཏནྟྲ» is the Sanskrit word mūlatantra spelled in Tibetan letters, not a title; another manual (MW2KG5015) cites 'the Mūlatantra' the same way for a trigram verse. Which root text is meant is not found (see the new question).
