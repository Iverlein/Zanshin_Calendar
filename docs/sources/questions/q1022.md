# What is «ཡུགས་ས་མ» in the be bum's rule «keep from the unclean, dogs, and especially ཡུགས་ས་མ» (Mipham, Gzhung 'grel skor vol. 28 image 190)? No sense found.

RD362.

## Answered 2026-11-13

A widow: «ཡུགས་ས་མ» (yugs sa ma) is the same word the White Beryl's death trigram uses for a widow (wb.2:p60-62); the rule keeps from the unclean, dogs and above all a widow in mourning (claim yugs-sa-ma-the-widow-in-mipham-dream-rule).
