# The Yu thog, Grwa thang and Peking etexts read «བརྗེད་ངས» in the first line and other etexts «བརྗེད་ངེས»: which does the Serthang print have on p. 31 or 32?

The Serthang scan lacks the leaf; the Drathang print has the lines.

## Answered 2026-11-10

Answered by RD288: on eight prints (Drathang, Zhol, Chag-po-ri, reprint, Derge, I3CN1711, I3CN1696, I3CN1702) the line reads «བརྗེད་ངས», none «བརྗེད་ངེས»; the Serthang leaf is absent from the pool, so that print is not seen (new question).
