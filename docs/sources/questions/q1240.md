# KP boxes 25, 20, 21, 17: is «དབུལ་ལག» the contraction of WB work 18's «དབུལ་པོ་ལག་སྟོང་» or an independent name?

KP boxes 16 and 17 print «དབུལ» alone.

## Answered 2026-11-21

An independent name in WB's own usage, the same lord as «དབུལ་པོ་ལག་སྟོང»: WB writes the lord's name both ways, so KP's «དབུལ་ལག» is not a contraction KP made.

1. WB vol. 2, ch. 31 lists the courses of the earth lords in a fixed run (earth-lord-courses.md, p. 230): 20 «གཟའ་རྒོད», 21 «དབུལ་པོ(༢༡)ལག་སྟོང་ཞེས་བྱ་བ། །སྟག་གི་ཟླ་བའི་གཅིག་བཅུ་གཅིག …», 22 «གཟའ་བདུན་ཟས་འཚོལ་ཕོ་ཉ་འགྱེད།».
2. WB vol. 2, ch. 33, p. 362 (wb.2:p362-363), the date's earth lords with works spoiled and a remedy, has the same run in the same order: «༈ གཟའ་རྒོད་འབྱུང་བ་ཟས་འཚོལ་དུས། …», then «༈ དབུལ་ལག་མཁར་ལས་འགོ་འཛུགས་དང་། །བག་མ་བུ་འབོགས་སྐྱེད་པུ་འཛུགས། …», then the Planet-envoy (གཟའ་བདུན་ཕོ་ཉ). The lord between the Planet-ogre and the Planet-envoy is called «དབུལ་པོ་ལག་སྟོང» in ch. 31 and «དབུལ་ལག» in ch. 33: one lord, two spellings, in the same book.
3. WB's work 60 and work 59 (ch. 34) print «དབུལ་ལག་འཆར»; only work 18 prints «དབུལ་པོ་ལག་སྟོང་དུས་ལ་འཛེམ» in full (BDRC phrase search «དབུལ་པོ་ལག་སྟོང», 16 hits, among them the two WB prints and the Vaidurya dkar po etext of the same text).

So KP's «དབུལ་ལག» (boxes 20, 25) is WB's short name, and box 16's and 17's «དབུལ» alone a further shortening of it. Whether work 18's full form is the sense or a metre-filled name is not said; the identification of the lord is settled.
