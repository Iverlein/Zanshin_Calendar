# Which years put the 大將軍 in which 仲

Which years put the 大將軍 in which 仲? The 暦林問答集 (§8, §54) gives four 仲 and three years in each, with no anchor; the modern table (亥子丑 west, 寅卯辰 north, 巳午未 east, 申酉戌 south) is the digests'. Which old text gives the assignment? (RD92)
