# Is Prajñāmaṇi (པྲཛྙཱ་མ་ཎི) the Sanskrit form of Khyenrab Norbu's name?

At whose request The Precious Key was gathered; Khyenrab Norbu (མཁྱེན་རབ་ནོར་བུ) wrote the life reckoning in the same print. By prajñā and maṇi: an inference, not a stated line. (RD181, 2026-11-07)
