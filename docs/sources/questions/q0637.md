# How gin and zon seal each other in the provisions

By what rule do gin and zon seal each other in the provisions (pp. 130–132), when the five seals of p. 124 leave both out?

RD180 second pass (2026-11-06), narrowed: the other seven blocks pair seal and wheel as seal = the trigram whose element overcomes the wheel's; by that rule gin and zon seal each other, and khon would take zin or zon; the elements are WB's as understood, and the match is an inference, not stated in the verses.
